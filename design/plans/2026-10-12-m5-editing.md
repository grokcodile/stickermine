# M5 Sticker Editing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make placed stickers editable. A double-click on a sticker (outside a capture session) brings it to the front of its display, makes its panel key and activates Stickermine; the sticker then shows a dashed outline, a full-frame hit pad and a corner knob, with a toolbar pill underneath. Dragging moves it (onto another display too), the knob scales and rotates it around its centre (Shift snaps to 15°), trackpad pinch and rotate do the same, and every gesture ends with a fresh bitmap rendered with the new scale and rotation baked in. The pill restyles the sticker with four inline previews, flips it, floats it on top and removes it; Delete removes it too. Esc, a click elsewhere, a click on another sticker, sleep, lock, a display going away, a panel rebuild and a session starting all end editing, throwing away a gesture or drag that was still in progress, and focus goes back to the app that was frontmost. Only user actions write the library.

**Architecture:** `StickerManager` keeps owning every panel and every library write; it creates one `StickerEditor` for the sticker being edited and drops it when editing ends. The editor takes the editing panel's events (keys, the corner knob, trackpad pinch and rotate, drags) and owns the `ToolbarPill`, a SwiftUI pill in a child panel that never becomes key. Pure math lives in `EditGeometry` (knob scale and angle from drag vectors, Shift snapping, scale limits, the end-of-gesture clamps, the gesture square) and in `Library`'s editing helpers (`LibraryEditing.swift`: bring to front, move to another display's list, restyle with `lastStyle`). A gesture or a drag puts a frame hold on its panel (`StickerManager.FrameHold`) so reconciles and late renders can't move it. A gesture grows the window once to a square, changes only the content sublayer's transform, then the manager writes the pose through `LayoutResolver.writing`, renders the new bitmap through the shared `StyleRenderer`, and shrinks the window and resets the transform when that bitmap is committed. A drag moves the window event by event (`StickerView` reports the mouse-down, each drag and the mouse-up in screen points), so it ends at the mouse-up whatever `performDrag` would have done (spike row 4); dropped on another display it becomes a placement there (`LayoutResolver.placing`, moved to that display's list, same on-screen size). Focus goes through an `EditingFocus` protocol (live: activate, make key, hand back to the previous app; tests: a recorder that never activates anything).

**Tech Stack:** Swift 5 language mode, AppKit (`NSPanel` child windows, mouse, key, magnify and rotate events), SwiftUI in `NSHostingView` (the pill), Core Animation (content-sublayer transforms, `CAShapeLayer` outline and knob), Swift Testing, `xcodebuild` (Xcode 27 beta locally, Xcode 26.6 on CI).

**Spec:** `design/specs/2026-10-12-stickermine-v1-design.md`. This milestone implements section 10 in full (inactive clicks, double-click to edit with bring-to-front saved, the outline and 1/255 hit pad over the padded frame, drag, the corner knob with Shift snapping, pinch and rotate, the scale limits, the toolbar pill with Style, Flip, Float on top and Remove, Delete, Esc and resign-key with the focus hand-back, the gesture lifecycle, editing ending mid-gesture, Remove), the editing parts of section 11 (bring to front, drag end, scale or rotate end, Style, Flip and Float on top as the only writes; the frame clamp and the 8 pt `visibleFrame` centre clamp at drag and gesture end; dragging across displays counting as a placement there with the on-screen size kept; re-rendering after a drop on a display with another backing scale), section 9's fallback click-through mode as it meets editing (the hidden `clickThroughFallback` setting is already read at launch since M2; editing now keeps the mouse during drags and gives it back as soon as editing ends), section 12's `lastStyle` on restyle, and section 5.2's session rules for editing (no editing while a session runs; a session starting ends editing and takes over the focus hand-back). The plan index with the Interface Contract is `design/plans/2026-10-12-stickermine-v1-plan.md`; the M1–M4 plans are `design/plans/2026-10-12-m1-foundation.md`, `design/plans/2026-10-12-m2-model-displays.md`, `design/plans/2026-10-12-m3-styles.md` and `design/plans/2026-10-12-m4-capture-picker.md`.

## Contract changes

Signature changes (every call written against the index still compiles, except item 1, whose only user was M1's spike):

1. **`StickerView.onDragEnded: (() -> Void)?` is replaced by `onMoveDrag: ((DragPhase, CGPoint) -> Void)?`**, and `mouseDown` no longer calls `window?.performDrag(with:)`. While editing, a mouse-down away from the knob starts a move drag; the view reports `.began`, every `.moved` and the `.ended` mouse-up with the cursor in screen coordinates, and `StickerEditor` moves the window itself. Why: the drag's end is then the mouse-up on every macOS version (spike row 4 asks whether `performDrag` even returns at the end), the pill can follow every step, a reconcile mid-drag can be held off, and the whole drag is testable with plain calls. Nothing else used `onDragEnded`.
2. **`StickerManager.init(library:screens:renderer:reconcileDelay:focus: EditingFocus? = nil)`**: nil means `LiveEditingFocus()`; tests pass a recorder so they never activate the app or make a panel key.
3. **`StickerManager.editingPlacement`** stays `UUID? { get }` but is now computed from the editor (`editor?.placementID`).
4. **`StickerManager.endEditing(discardGesture:returningFocus:) -> NSRunningApplication?`** (`@discardableResult`) is added next to the contract's `endEditing(discardGesture:)`, which calls it with `returningFocus: true`. With `false` it keeps focus where it is and returns the app it would have handed focus to (also when a click on another sticker ended editing a moment ago and its hand-back is still waiting, which it then cancels); `SessionCoordinator` uses that when a session starts, so the session hands focus back to that app when it ends (M4's `begin(_:)` changes accordingly).
5. **`ClickThroughFallback.init(targets:buttonsDown: (() -> Bool)? = nil)`**: nothing switches while a mouse button is held, so a drag or a knob drag that leaves the sticker's pixels keeps the mouse. nil means `NSEvent.pressedMouseButtons != 0`.

Deviations from the spec's wording, all within its intent:

- **Window margin while editing.** A None sticker has no shadow margin, so its knob would sit half outside the window. While editing, the window keeps at least `StickerView.editingMargin` (14 pt) on every side; the hit pad covers that padded frame. Not editing, the frame is exactly section 9's.
- **Gesture square.** At gesture start the side is the shown bitmap's diagonal × min(2, the largest factor the scale limits allow) + the margin on both sides. Each time a pinch or the knob takes the sticker past the square's headroom, the square grows again (to 1.5 × the current factor, within the limits): rarely, never per event, and a sticker can still reach its display's long side in one gesture.
- **A sticker already outside the scale limits** (a capture smaller than 48 pt): the knob and pinch stop where it is in that direction; it never jumps to the limit.
- **The pill's 8 pt gap is measured from the knob.** The knob sits on the outline's bottom-right corner and reaches 9 pt below the sticker (`outlineOutset` + `knobRadius`), so the pill sits 8 pt below that and never covers it; above the sticker it keeps the same 9 + 8 pt.
- **The pill stays on its display.** Centred under the sticker with the 8 pt gap; above it when there's no room below in the display's visible frame; moved sideways to stay inside that visible frame near an edge; over the sticker's lower edge when neither below nor above fits (a sticker as tall as the display). During a drag it uses the display under the sticker.
- **A click on another sticker ends editing.** A sticker that isn't being edited can't become key, so clicking it may not make the edited panel resign key (spike row 8); any mouse-down on another sticker ends editing. That click may be the first of a double-click on the other sticker, so its focus hand-back waits for the double-click interval (`NSEvent.doubleClickInterval`); a double-click or a session starting in the meantime takes it over, so switching stickers never brings the previous app forward in between.
- **Delete removes on the next run-loop turn**, so the panel isn't closed inside its own key event. Esc is key code 53; Delete is 51 or 117 (forward delete).
- **Picking a style in the pill keeps the style row open**, so several can be tried; the selected one is highlighted.
- **Sleep and lock** are `NSWorkspace.willSleepNotification`, `NSWorkspace.screensDidSleepNotification` and the distributed `com.apple.screenIsLocked`.
- **Focus hand-back** runs on the next run-loop turn and only while Stickermine is still active and no other Stickermine window took key, so a click into another app keeps that app frontmost. When Stickermine itself was frontmost before editing (no previous app), another visible Stickermine window that can be key gets it back (M6's Home), else Stickermine deactivates.

## Global Constraints

All constraints in the index apply. Milestone-specific ones, verbatim from the spec:

- "**Double-click** (`clickCount == 2`, outside a session) enters editing. `StickerView.acceptsFirstMouse` returns true; `StickerPanel.canBecomeKey` returns true while editing. Make the panel key, move the placement to the end of its display's list (the front; this is saved), and activate the app so keys and trackpad gestures arrive. Gesture delivery to a key panel of an active accessory app is expected but unverified; the corner knob is the guaranteed path." (section 10)
- "A subtle outline, and a full-bounds hit pad (alpha 1/255) covering the padded frame so the whole box and the knob can be grabbed." (section 10)
- "**Corner knob** (bottom-right): one drag scales and rotates around the centre. Shift snaps rotation to 15°." … "**Scale limits:** the sticker's long side stays between 48 pt and its display's long side; the knob and pinch stop at those limits." (section 10)
- "**Toolbar pill:** a child panel that never becomes key (keep the borderless default `canBecomeKey == false`; controls accept first mouse), so using it never ends editing. It holds **Style** (the four previews expand inline inside the pill, never in a popover or menu), **Flip** (horizontal), **Float on top**, **Remove**. It sits centred under the sticker with an 8 pt gap, moves above it when there's no room on the sticker's display, follows the sticker during drags, and uses the sticker's level and collection behaviour." (section 10)
- "**Delete** removes. **Esc**, or clicking elsewhere (the panel resigns key), ends editing and returns focus to the previously frontmost app." (section 10)
- "**During a gesture:** at gesture start, grow the window to a square of side = (the bitmap's diagonal × scale headroom) + the shadow margin. Apply an affine transform to the content sublayer inside `CATransaction.setDisableActions(true)`. Don't resize the window per event." (section 10)
- "**At gesture end:** re-render with rotation, flip and scale baked in (so the shadow points down and the Puffy light stays top-left in screen space), shrink the window to the padded bounding box (section 9) around the unchanged centre, reset the sublayer transform, and save the new pose." (section 10)
- "**Editing ending mid-gesture** (Esc, resigning key, the panel being ordered out by a display change, sleep, lock, a session starting, or a panel rebuild): discard the gesture. Reset the sublayer transform, restore the frame from the last saved pose, remove the hit pad and pill, and write nothing." (section 10)
- "**Remove** deletes the placement only; the sticker stays in history. Tutorial stickers are deleted outright (section 13)." (section 10; M2's `remove(placement:)` already does both)
- "**Hard rule: only user actions write layout data:** place, drag end, scale or rotate end, bring to front (entering editing), Style, Flip, Float on top, Remove, delete from history. Display events, `windowDidMove` and `windowDidChangeScreen` never write. Clamping happens when drawing and is saved only when it results from a user gesture." (section 11)
- "At drag or gesture end and when deriving a pose for a new size, also clamp so the sticker's centre lies inside `visibleFrame` inset by 8 pt, so a sticker never ends up unreachable under the menu bar or Dock." (section 11)
- "**Dragging across displays:** when a drag ends with the sticker's centre on another display (`NSMouseInRect(p, frame, false)`, else the nearest screen), it counts as a placement on that display: move the placement to that display's list (creating its record if needed), on top, with `poses = [B: pose]` and scale chosen so the sticker's on-screen point size is unchanged." (section 11)
- "**Writes:** placing sets `poses = [B: pose]`. Moving or scaling writes only `poses[B]` (creating it if the pose was borrowed). Rotation, style, flip and float on top are shared across sizes." (section 11) "`lastStyle` is set when a sticker is first confirmed and whenever any of its placements is restyled" (section 12).
- "**Fallback click-through mode** (hidden setting `clickThroughFallback`, section 12; read at launch): every sticker gets an explicit `ignoresMouseEvents = true`, and the sticker under the cursor is switched to `false` while the cursor is over its opaque pixels … A change takes effect on relaunch, since live windows can't return to alpha hit-testing." (section 9) `ClickThroughFallback.swift` stays the only file in `Stickers/` that writes the flag (`PanelPolicyTests.stickerCodeNeverWritesTheMouseEventFlagOrTheFloatingFlag` scans `StickerEditor.swift`, `ToolbarPill.swift` and `EditGeometry.swift` too).
- "While a session is active, … double-clicks on stickers don't enter editing. Starting a session first ends any sticker's editing, discarding an in-progress gesture." (section 5.2)
- From M2–M4, unchanged: every display a test builds sits at x ≥ 40 000 pt, and every test that orders a panel in closes it (`finish()`) before it suspends or returns, so the test host never shows a window; a test renders the bitmaps it needs before it orders any panel in. enum EditGeometry {

```text
    static let minimumLongSide: Double          // 48
    static let gestureHeadroom: Double          // 2
    struct KnobChange: Equatable { let scale: Double; let rotation: Double }
    static func normalized(_ angle: Double) -> Double                                // (−π, π]
    static func snapped(_ angle: Double, step: Double = snapStep) -> Double
    static func knobChange(from start: CGVector, to current: CGVector, baseRotation: Double, snap: Bool) -> KnobChange
    static func scaleLimits(natural: CGSize, displaySize: CGSize) -> ClosedRange<Double>   // pose scales
    static func clampedScale(_ proposed: Double, current: Double, limits: ClosedRange<Double>) -> Double
    static func settledCenter(_ center: CGPoint, boxSize: CGSize, frame: CGRect, visibleFrame: CGRect) -> CGPoint
    static func gestureSide(contentSize: CGSize, factor: Double, margin: CGFloat) -> CGFloat
}
```

```swift
import CoreGraphics

@testable import Stickermine

struct EditGeometryTests {
    private let degree = Double.pi / 180

    @Test func anglesAreNormalizedIntoMinusPiToPi() {
        #expect(EditGeometry.normalized(0) == 0)
        #expect(abs(EditGeometry.normalized(3 * Double.pi / 2) + Double.pi / 2) < 1e-12)
```

```swift
import CoreGraphics
import Foundation

/// The pure math behind editing a sticker (spec sections 10 and 11): the
/// corner knob, Shift snapping, the scale limits, where a sticker settles at
/// the end of a drag or gesture, and how big the window grows for a gesture.
/// Rotations are radians, counter-clockwise on screen (Cocoa, y up).
enum EditGeometry {
    /// Shift snaps the knob's rotation to multiples of 15°.
    static let snapStep = Double.pi / 12
    /// A sticker's long side never goes below this many points.
    static let minimumLongSide: Double = 48
    /// At a gesture's start the window grows to fit the sticker at up to this
    /// multiple of its size, turned any way.
    static let gestureHeadroom: Double = 2

    /// The knob's change since its drag began: a factor on the scale the drag
    /// started with, and a rotation to add to the rotation it started with.
    struct KnobChange: Equatable {
        let scale: Double
        let rotation: Double
    }

    /// `angle` in (−π, π].
    static func normalized(_ angle: Double) -> Double {
        var result = remainder(angle, 2 * Double.pi)
        if result <= -Double.pi { result += 2 * Double.pi }
        return result
    }

    /// The multiple of `step` nearest to `angle`, normalized.
    static func snapped(_ angle: Double, step: Double = snapStep) -> Double {
        normalized((angle / step).rounded() * step)
    }

    /// One knob drag: `start` and `current` point from the sticker's centre to
    /// where the drag began and to the cursor now. The scale follows the
    /// distance from the centre and the rotation the angle around it, so the
    /// knob stays under the cursor. With `snap` (Shift held), the sticker's
    /// resulting rotation, `baseRotation` plus the change, lands on a
    /// multiple of 15°.
    static func knobChange(from start: CGVector, to current: CGVector, baseRotation: Double,
                           snap: Bool) -> KnobChange {
        let startLength = Double(hypot(start.dx, start.dy))
        guard startLength > 0 else { return KnobChange(scale: 1, rotation: 0) }
        let scale = Double(hypot(current.dx, current.dy)) / startLength
        var rotation = normalized(Double(atan2(current.dy, current.dx)) - Double(atan2(start.dy, start.dx)))
        if snap {
            rotation = normalized(snapped(baseRotation + rotation) - baseRotation)
        }
        return KnobChange(scale: scale, rotation: rotation)
    }

    /// The pose scales a sticker of `natural` point size may have on a display
    /// of `displaySize` points: its long side between 48 pt and the display's
    /// long side.
    static func scaleLimits(natural: CGSize, displaySize: CGSize) -> ClosedRange<Double> {
        let longSide = Double(max(natural.width, natural.height))
        guard longSide > 0 else { return 1...1 }
        let lower = minimumLongSide / longSide
        let upper = Double(max(displaySize.width, displaySize.height)) / longSide
        return lower...max(lower, upper)
    }

    /// `proposed` stopped at `limits`. A sticker that is already outside them
    /// (one captured smaller than 48 pt) is never pushed further out and never
    /// jumps in: the knob and pinch just stop.
    static func clampedScale(_ proposed: Double, current: Double, limits: ClosedRange<Double>) -> Double {
        let lower = min(limits.lowerBound, current)
        let upper = max(limits.upperBound, current)
        return min(max(proposed, lower), upper)
    }

    /// Where a sticker's centre settles when a drag or gesture ends: inside
    /// `visibleFrame` inset by 8 pt (never unreachable under the menu bar or
    /// Dock), with its `boxSize` box inside the display's `frame` (spec
    /// section 11).
    static func settledCenter(_ center: CGPoint, boxSize: CGSize, frame: CGRect, visibleFrame: CGRect) -> CGPoint {
        let reachable = StickerGeometry.reachableCenter(center, visibleFrame: visibleFrame)
        let rect = StickerGeometry.clampedRect(size: boxSize, center: reachable, within: frame)
        return StickerGeometry.reachableCenter(CGPoint(x: rect.midX, y: rect.midY), visibleFrame: visibleFrame)
    }

    /// The side of the square window a gesture uses: the shown bitmap's
    /// diagonal at `factor` times its size (so it can turn freely), plus
    /// `margin` on every side, rounded up to whole points.
    static func gestureSide(contentSize: CGSize, factor: Double, margin: CGFloat) -> CGFloat {
        (hypot(contentSize.width, contentSize.height) * CGFloat(factor) + 2 * margin).rounded(.up)
    }
}
```

```swift
import Foundation

/// The changes editing makes (spec sections 10 and 11). Each returns false,
/// changing nothing, when what it names is unknown or already so.
extension Library {
    /// Moves the placement to the end of its display's list: the front of
    /// that display's z-order.
    @discardableResult
    mutating func bringToFront(_ id: UUID) -> Bool {
        guard let key = displayKey(containing: id), var record = displays[key],
              let index = record.placements.firstIndex(where: { $0.id == id }),
              index < record.placements.count - 1
        else { return false }
        record.placements.append(record.placements.remove(at: index))
        displays[key] = record
        return true
    }

    /// Changes one placement wherever it is.
    @discardableResult
    mutating func updatePlacement(_ id: UUID, _ change: (inout Placement) -> Void) -> Bool {
        guard let key = displayKey(containing: id), var record = displays[key],
              let index = record.placements.firstIndex(where: { $0.id == id })
        else { return false }
        change(&record.placements[index])
        displays[key] = record
        return true
    }

    /// Moves the placement to the front of the display record `key` (a drop
    /// on another display).
    @discardableResult
    mutating func movePlacement(_ id: UUID, toDisplay key: String) -> Bool {
        guard displays[key] != nil, let placement = removePlacement(id) else { return false }
        displays[key]?.placements.append(placement)
        return true
    }

    /// Restyles the placement and makes the style its sticker's `lastStyle`
    /// (spec section 12).
    @discardableResult
    mutating func restyle(_ id: UUID, to style: StickerStyle) -> Bool {
        guard let sticker = placement(id)?.sticker, placement(id)?.style != style else { return false }
        updatePlacement(id) { $0.style = style }
        if let index = stickers.firstIndex(where: { $0.id == sticker }) {
            stickers[index].lastStyle = style
        }
        return true
    }
}
```

```swift
import AppKit
import QuartzCore

/// The content view of a StickerPanel: a layer-hosting view whose root layer
/// holds three sublayers we own, back to front:
/// - `hitPadLayer`: alpha 1/255 over the whole padded frame while editing, so the
///   transparent parts of the box and the corner knob can be grabbed; hidden
///   otherwise, so transparent pixels click through.
/// - `contentLayer`: the sticker bitmap (CGImage or IOSurface), centred, with the
///   layer shadow. Gesture transforms go on this layer, never on the root.
/// - `outlineLayer`: the subtle editing outline, with the corner knob
///   (`knobLayer`) as its sublayer, so both show and hide together.
@MainActor
final class StickerView: NSView {
    /// A drag's steps: the mouse-down, each move, the mouse-up.
    enum DragPhase: Equatable {
        case began, moved, ended
    }

    /// What a drag that started while editing is doing.
    enum DragKind: Equatable {
        /// Started on the corner knob: scale and rotate.
        case knob
        /// Started anywhere else in the frame: move the sticker.
        case move
    }

    let contentLayer = CALayer()
    let hitPadLayer = CALayer()
    let outlineLayer = CAShapeLayer()
    let knobLayer = CAShapeLayer()

    /// A double-click on an inactive (not editing) sticker.
    var onDoubleClick: (() -> Void)?
    /// Every mouse-down on a sticker that isn't being edited (before
    /// `onDoubleClick` for the second click of a double-click).
    var onInactiveMouseDown: (() -> Void)?
    /// Key presses while the panel is key. Return true when handled.
    var onKeyDown: ((NSEvent) -> Bool)?
    /// Trackpad pinch and rotate, delivered whatever the editing state.
    var onMagnify: ((NSEvent) -> Void)?
    var onRotate: ((NSEvent) -> Void)?
    /// A drag that started away from the knob while editing (moving the
    /// sticker): the phase and the cursor in screen coordinates.
    var onMoveDrag: ((DragPhase, CGPoint) -> Void)?
    /// A drag that started on the corner knob while editing: the phase, the
    /// cursor in screen coordinates, and whether Shift is held.
    var onKnobDrag: ((DragPhase, CGPoint, Bool) -> Void)?
    /// The window's backing scale after it changed (moved to a display with
    /// another scale, or the display's scale changed): the bitmap must be
    /// re-rendered at the new scale (spec section 11).
    var onBackingScaleChange: ((CGFloat) -> Void)?

    /// The sticker's unrotated, unscaled size in points (the bitmap's bounds).
    private(set) var contentPointSize: CGSize = .zero
    private(set) var layerShadow: LayerShadow?
    /// The transparent padding the window keeps on every side of the shown
    /// bitmap's box, in points: `StyleParameters.shadowMargin(for:)` rounded up
    /// to whole pixels, over the backing scale, for a rendered sticker;
    /// `LayerShadow.margin` for raw contents; 0 without a shadow (spec section 9).
    private(set) var frameMargin: CGFloat = 0
    private(set) var contentScale: CGFloat = 1
    private(set) var contentRotation: CGFloat = 0
    private(set) var isShowingEditingChrome = false
    /// The knob's centre in this view's coordinates: the bottom-right corner
    /// of the (transformed) outline.
    private(set) var knobCenter: CGPoint = .zero
    /// The drag in progress, from its mouse-down to its mouse-up.
    private(set) var trackedDrag: DragKind?

    static let hitPadAlpha: CGFloat = 1.0 / 255.0
    /// The outline sits this far outside the bitmap's box.
    static let outlineOutset: CGFloat = 2
    static let knobRadius: CGFloat = 7
    /// A mouse-down this close to the knob's centre grabs the knob.
    static let knobHitRadius: CGFloat = 12
    /// While editing, the window keeps at least this much room on every side
    /// of the bitmap's box, so the knob is never clipped and can be grabbed
    /// (a None sticker has no shadow margin).
    static let editingMargin: CGFloat = 14

    override init(frame frameRect: NSRect) {
        super.init(frame: frameRect)
        let root = CALayer()
        root.isOpaque = false
        // Assigning the layer before wantsLayer makes this a layer-hosting view:
        // AppKit leaves the layer tree to us.
        layer = root
        wantsLayer = true

        hitPadLayer.backgroundColor = NSColor(white: 0, alpha: Self.hitPadAlpha).cgColor
        hitPadLayer.isHidden = true

        contentLayer.contentsGravity = .resize
        contentLayer.minificationFilter = .trilinear

        outlineLayer.fillColor = nil
        outlineLayer.strokeColor = NSColor.controlAccentColor.withAlphaComponent(0.9).cgColor
        outlineLayer.lineWidth = 1.5
        outlineLayer.lineDashPattern = [5, 4]
        outlineLayer.isHidden = true

        let r = Self.knobRadius
        knobLayer.path = CGPath(ellipseIn: CGRect(x: -r, y: -r, width: 2 * r, height: 2 * r), transform: nil)
        knobLayer.fillColor = NSColor.white.cgColor
        knobLayer.strokeColor = NSColor.controlAccentColor.cgColor
        knobLayer.lineWidth = 1.5
        knobLayer.shadowColor = NSColor.black.cgColor
        knobLayer.shadowOpacity = 0.3
        knobLayer.shadowRadius = 1.5
        knobLayer.shadowOffset = CGSize(width: 0, height: -0.5)
        outlineLayer.addSublayer(knobLayer)

        root.addSublayer(hitPadLayer)
        root.addSublayer(contentLayer)
        root.addSublayer(outlineLayer)
        layoutStickerLayers()
    }

    required init?(coder: NSCoder) {
        fatalError("StickerView is only created in code")
    }

    /// The window size for a sticker of `pointSize` with `shadow`: the sticker
    /// rect plus the shadow margin on every side (zero margin without a shadow).
    static func frameSize(pointSize: CGSize, shadow: LayerShadow?) -> CGSize {
        let margin = shadow?.margin ?? 0
        return CGSize(width: pointSize.width + 2 * margin, height: pointSize.height + 2 * margin)
    }

    /// The axis-aligned bounding box of `size` scaled by `scale` and rotated by
    /// `rotation` radians. The rotation math lives in one place,
    /// `StickerGeometry.boundingSize(of:rotation:)` (M2); this only scales it.
    static func boundingSize(of size: CGSize, scale: CGFloat, rotation: CGFloat) -> CGSize {
        let box = StickerGeometry.boundingSize(of: size, rotation: Double(rotation))
        return CGSize(width: box.width * scale, height: box.height * scale)
    }

    /// The room the window keeps around the bitmap's box: the shadow margin,
    /// and at least `editingMargin` while the editing chrome shows.
    var windowMargin: CGFloat {
        isShowingEditingChrome ? max(frameMargin, Self.editingMargin) : frameMargin
    }

    /// Shows `contents` (a CGImage or an IOSurface, as accepted by
    /// `CALayer.contents`) at `pointSize`, with an optional layer shadow.
    /// `frameMargin` defaults to the shadow's own margin (0 without one);
    /// `show(_:shadow:style:)` passes `StyleParameters.shadowMargin` in points.
    func showContents(_ contents: Any, pointSize: CGSize, shadow: LayerShadow?, frameMargin: CGFloat? = nil) {
        contentPointSize = pointSize
        layerShadow = shadow
        self.frameMargin = frameMargin ?? shadow?.margin ?? 0
        withoutAnimation {
            contentLayer.contents = contents
            if let shadow {
                contentLayer.shadowColor = NSColor.black.cgColor
                contentLayer.shadowOpacity = shadow.opacity
                contentLayer.shadowRadius = shadow.radius
                // Layer-hosting views aren't flipped: negative y points down.
                contentLayer.shadowOffset = CGSize(width: 0, height: -shadow.offset)
            } else {
                contentLayer.shadowOpacity = 0
            }
        }
        layoutStickerLayers()
    }

    /// Shows a rendered sticker at its point bounds with its drop shadow:
    /// `shadow` holds the style parameters for the sticker's on-screen pixel
    /// size (`RenderRequest.onScreenParameters(sourceLongSide:)`), which become
    /// points through the backing scale the bitmap was rendered for. None, or
    /// a nil `shadow`, shows no shadow and needs no margin (spec sections 8–9).
    /// The shadow stays unrasterized: the content is static between gestures.
    func show(_ rendered: RenderedSticker, shadow: StyleParameters?, style: StickerStyle) {
        let layer = Self.layerShadow(for: shadow, style: style, backingScale: rendered.backingScale)
        // Whole device pixels, so the bitmap stays on the pixel grid inside the
        // backing-aligned frame (spec section 9).
        let pixels = CGFloat(shadow?.shadowMargin(for: style) ?? 0).rounded(.up)
        let margin = layer == nil ? 0 : pixels / rendered.backingScale
        showContents(rendered.contents, pointSize: rendered.pointBounds, shadow: layer, frameMargin: margin)
    }

    /// The layer shadow for pixel `parameters` at `backingScale`: black at the
    /// parameters' opacity, radius and downward offset in points. nil for None,
    /// without parameters, or when the radius is zero.
    static func layerShadow(for parameters: StyleParameters?, style: StickerStyle,
                            backingScale: CGFloat) -> LayerShadow? {
        guard let parameters, style != .none, backingScale > 0, parameters.shadowRadius > 0 else { return nil }
        return LayerShadow(radius: CGFloat(parameters.shadowRadius) / backingScale,
                           opacity: Float(parameters.shadowOpacity),
                           offset: CGFloat(parameters.shadowOffset) / backingScale)
    }

    /// Drops the bitmap. Call before ordering out and closing a panel for good:
    /// a closed window keeps its contents alive until the next event otherwise.
    func clearContents() {
        withoutAnimation { contentLayer.contents = nil }
    }

    /// Scales and rotates the content around its centre (a live gesture
    /// preview); the outline and the knob follow it.
    func setContentTransform(scale: CGFloat, rotation: CGFloat) {
        contentScale = scale
        contentRotation = rotation
        withoutAnimation {
            contentLayer.transform = CATransform3DScale(
                CATransform3DMakeRotation(rotation, 0, 0, 1), scale, scale, 1)
            updateOutlinePath()
        }
    }

    /// The hit pad, outline and knob shown while the sticker is being edited.
    /// Hiding them also forgets a drag in progress.
    func setEditingChrome(_ visible: Bool) {
        isShowingEditingChrome = visible
        if !visible { trackedDrag = nil }
        withoutAnimation {
            hitPadLayer.isHidden = !visible
            outlineLayer.isHidden = !visible
        }
    }

    /// Whether a mouse-down at `point` (this view's coordinates) grabs the knob.
    func isOnKnob(_ point: CGPoint) -> Bool {
        isShowingEditingChrome && hypot(point.x - knobCenter.x, point.y - knobCenter.y) <= Self.knobHitRadius
    }

    /// Layer-hosting views don't pass the backing scale to their sublayers, so the
    /// dashed outline and the knob (the layers that draw vector content) get it
    /// here: when the view joins a window and whenever that window's scale changes.
    override func viewDidMoveToWindow() {
        super.viewDidMoveToWindow()
        matchOutlineToBackingScale()
    }

    override func viewDidChangeBackingProperties() {
        super.viewDidChangeBackingProperties()
        matchOutlineToBackingScale()
        if let scale = window?.backingScaleFactor { onBackingScaleChange?(scale) }
    }

    private func matchOutlineToBackingScale() {
        guard let scale = window?.backingScaleFactor else { return }
        withoutAnimation {
            outlineLayer.contentsScale = scale
            knobLayer.contentsScale = scale
        }
    }

    override func setFrameSize(_ newSize: NSSize) {
        super.setFrameSize(newSize)
        layoutStickerLayers()
    }

    private func layoutStickerLayers() {
        withoutAnimation {
            hitPadLayer.frame = bounds
            outlineLayer.frame = bounds
            contentLayer.bounds = CGRect(origin: .zero, size: contentPointSize)
            contentLayer.position = CGPoint(x: bounds.midX, y: bounds.midY)
            updateOutlinePath()
        }
    }

    /// The outline is the bitmap's box, scaled and turned with the content
    /// and set `outlineOutset` outside it; the knob sits on its bottom-right
    /// corner.
    private func updateOutlinePath() {
        let width = contentPointSize.width * contentScale + 2 * Self.outlineOutset
        let height = contentPointSize.height * contentScale + 2 * Self.outlineOutset
        var transform = CGAffineTransform(translationX: bounds.midX, y: bounds.midY).rotated(by: contentRotation)
        let rect = CGRect(x: -width / 2, y: -height / 2, width: width, height: height)
        outlineLayer.path = CGPath(rect: rect, transform: &transform)
        knobCenter = CGPoint(x: width / 2, y: -height / 2).applying(transform)
        knobLayer.position = knobCenter
    }

    private func withoutAnimation(_ body: () -> Void) {
        CATransaction.begin()
        CATransaction.setDisableActions(true)
        body()
        CATransaction.commit()
    }

    // MARK: Events

    /// The first click on a sticker of an inactive app must reach us.
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }
    override var mouseDownCanMoveWindow: Bool { false }
    override var acceptsFirstResponder: Bool { true }

    override func mouseDown(with event: NSEvent) {
        let editing = (window as? StickerPanel)?.isEditing ?? false
        guard editing else {
            // Inactive stickers absorb single clicks; a double-click starts editing.
            onInactiveMouseDown?()
            if event.clickCount == 2 { onDoubleClick?() }
            return
        }
        // The window follows the mouse here, event by event (not the window
        // server's performDrag), so the drag's end is the mouse-up and the pill
        // can follow every step.
        let kind: DragKind = isOnKnob(convert(event.locationInWindow, from: nil)) ? .knob : .move
        trackedDrag = kind
        report(kind, .began, event)
    }

    override func mouseDragged(with event: NSEvent) {
        guard let kind = trackedDrag else { return }
        report(kind, .moved, event)
    }

    override func mouseUp(with event: NSEvent) {
        guard let kind = trackedDrag else { return }
        trackedDrag = nil
        report(kind, .ended, event)
    }

    private func report(_ kind: DragKind, _ phase: DragPhase, _ event: NSEvent) {
        let point = screenLocation(of: event)
        switch kind {
        case .knob: onKnobDrag?(phase, point, event.modifierFlags.contains(.shift))
        case .move: onMoveDrag?(phase, point)
        }
    }

    private func screenLocation(of event: NSEvent) -> CGPoint {
        window?.convertPoint(toScreen: event.locationInWindow) ?? NSEvent.mouseLocation
    }

    override func keyDown(with event: NSEvent) {
        if onKeyDown?(event) == true { return }
        super.keyDown(with: event)
    }

    override func magnify(with event: NSEvent) {
        onMagnify?(event)
    }

    override func rotate(with event: NSEvent) {
        onRotate?(event)
    }
}
```

```swift
import AppKit
import SwiftUI
import os

/// The pill's window: borderless, so it never becomes key; using it never
/// takes key status from the sticker being edited (spec section 10).
@MainActor
final class ToolbarPillPanel: NSPanel {
    override var canBecomeKey: Bool { false }
    override var canBecomeMain: Bool { false }
}

/// A hosting view whose controls take the first click, so a click on the pill
/// acts at once even though its window is never key.
@MainActor
final class FirstClickHostingView<Content: View>: NSHostingView<Content> {
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }
}

/// What the pill shows and does: Style (four previews inline, in UI order),
/// Flip, Float on top and Remove for the placement being edited.
@MainActor
final class ToolbarPillModel: ObservableObject {
    /// Each style preview fits in this box (points).
    static let previewBox = CGSize(width: 40, height: 40)

    @Published private(set) var style: StickerStyle
    @Published private(set) var flipped: Bool
    @Published private(set) var onTop: Bool
    @Published private(set) var showsStyles = false
    @Published private(set) var previews: [StickerStyle: PickerModel.Preview] = [:]
    /// The order previews were rendered in (tests).
    private(set) var renderOrder: [StickerStyle] = []

    var onStyle: ((StickerStyle) -> Void)?
    var onFlip: (() -> Void)?
    var onFloatOnTop: (() -> Void)?
    var onRemove: (() -> Void)?
    /// The pill's size changed (the style row opened or closed).
    var onResize: (() -> Void)?

    let sticker: UUID
    let natural: CGSize
    let sourceLongSide: Double
    private let renderer: StyleRenderer
    private let backingScale: CGFloat
    private var previewTask: Task<Void, Never>?
    private let log = Logger(subsystem: "com.ethan.stickermine", category: "editing")

    init(placement: Placement, natural: CGSize, sourceLongSide: Double, renderer: StyleRenderer,
         backingScale: CGFloat) {
        style = placement.style
        flipped = placement.flipped
        onTop = placement.onTop
        sticker = placement.sticker
        self.natural = natural
        self.sourceLongSide = sourceLongSide
        self.renderer = renderer
        self.backingScale = backingScale
    }

    /// Opens or closes the style row; opening renders the four previews.
    func toggleStyles() {
        showsStyles.toggle()
        if showsStyles { renderPreviews() }
        onResize?()
    }

    func choose(_ style: StickerStyle) { perform { [weak self] in self?.onStyle?(style) } }
    func flip() { perform { [weak self] in self?.onFlip?() } }
    func floatOnTop() { perform { [weak self] in self?.onFloatOnTop?() } }
    func remove() { perform { [weak self] in self?.onRemove?() } }

    /// The placement changed (a button acted, or something else wrote it).
    func update(style: StickerStyle, flipped: Bool, onTop: Bool) {
        let flipChanged = flipped != self.flipped
        if style != self.style { self.style = style }
        if flipChanged { self.flipped = flipped }
        if onTop != self.onTop { self.onTop = onTop }
        if flipChanged && showsStyles { renderPreviews() }
    }

    /// The preview request for `style`: unrotated, flipped like the
    /// placement, the natural size fitted into `previewBox`.
    func previewRequest(for style: StickerStyle) -> RenderRequest {
        let scale = natural.width > 0 && natural.height > 0
            ? min(Self.previewBox.width / natural.width, Self.previewBox.height / natural.height) : 1
        return RenderRequest(sticker: sticker, style: style, flipped: flipped, rotation: 0,
                             pointSize: CGSize(width: natural.width * scale, height: natural.height * scale),
                             backingScale: backingScale)
    }

    /// Renders the four previews in UI order through the app's renderer,
    /// skipping any that is already current.
    func renderPreviews() {
        previewTask?.cancel()
        let requests = StickerStyle.allCases.map(previewRequest(for:))
        let renderer = self.renderer
        previewTask = Task { [weak self] in
            for request in requests {
                guard let self, !Task.isCancelled else { return }
                if self.previews[request.style]?.request == request { continue }
                do {
                    let rendered = try await renderer.render(request)
                    guard !Task.isCancelled else { return }
                    let shadow = request.onScreenParameters(sourceLongSide: self.sourceLongSide)
                    self.previews[request.style] = PickerModel.Preview(request: request, rendered: rendered,
                                                                       shadow: shadow)
                    self.renderOrder.append(request.style)
                } catch {
                    self.log.error("pill preview \(request.style.rawValue, privacy: .public) failed: \(String(describing: error), privacy: .public)")
                }
            }
        }
    }

    /// Stops rendering previews (the pill closed).
    func cancel() {
        previewTask?.cancel()
        previewTask = nil
    }

    /// A pill button acts once SwiftUI has finished handling the click:
    /// Remove closes the pill's own window.
    private func perform(_ action: @escaping @MainActor () -> Void) {
        Task { @MainActor in action() }
    }
}

/// The toolbar pill (spec section 10): a child panel of the sticker being
/// edited, at the sticker's level and with its collection behaviour, centred
/// under the sticker with an 8 pt gap, or above it when there's no room
/// below on the sticker's display. It follows the sticker (a child window
/// moves with its parent) and never becomes key.
@MainActor
final class ToolbarPill {
    nonisolated static let gap: CGFloat = 8

    let panel: ToolbarPillPanel
    let model: ToolbarPillModel
    private let host: FirstClickHostingView<ToolbarPillView>
    private var lastPlacement: (stickerRect: CGRect, visibleFrame: CGRect)?

    init(model: ToolbarPillModel) {
        self.model = model
        panel = Self.makePanel()
        host = FirstClickHostingView(rootView: ToolbarPillView(model: model))
        panel.contentView = host
        panel.setContentSize(size)
        model.onResize = { [weak self] in self?.refit() }
    }

    /// The panel policy (spec section 4): not released on close, never hidden
    /// on deactivation, the floating-panel flag untouched, the level last.
    static func makePanel() -> ToolbarPillPanel {
        let panel = ToolbarPillPanel(contentRect: NSRect(x: 0, y: 0, width: 320, height: 40),
                                     styleMask: [.borderless, .nonactivatingPanel], backing: .buffered, defer: false)
        PanelPolicy.applyCommon(to: panel, hidesOnDeactivate: false)
        panel.isOpaque = false
        panel.backgroundColor = .clear
        panel.hasShadow = true
        panel.canHide = false
        panel.animationBehavior = .none
        panel.collectionBehavior = PanelPolicy.stickerBehavior
        panel.level = PanelPolicy.stickerLevel  // last
        return panel
    }

    /// Where a pill of `size` goes for a sticker whose box is `stickerRect`:
    /// centred under it with `gap`; above it when that leaves `visibleFrame`;
    /// over the sticker's lower edge when neither fits. Always inside
    /// `visibleFrame`, on whole points.
    nonisolated static func frame(size: CGSize, stickerRect: CGRect, visibleFrame: CGRect,
                                  gap: CGFloat = gap) -> CGRect {
        let size = CGSize(width: size.width.rounded(.up), height: size.height.rounded(.up))
        var origin = CGPoint(x: stickerRect.midX - size.width / 2, y: stickerRect.minY - gap - size.height)
        if origin.y < visibleFrame.minY {
            origin.y = stickerRect.maxY + gap
            if origin.y + size.height > visibleFrame.maxY {
                origin.y = stickerRect.minY + gap
            }
        }
        origin.x = min(max(origin.x, visibleFrame.minX), max(visibleFrame.minX, visibleFrame.maxX - size.width))
        origin.y = min(max(origin.y, visibleFrame.minY), max(visibleFrame.minY, visibleFrame.maxY - size.height))
        return CGRect(origin: CGPoint(x: origin.x.rounded(), y: origin.y.rounded()), size: size)
    }

    /// The pill's size for its current content. SwiftUI applies a model
    /// change at the next layout pass, so lay out first.
    var size: CGSize {
        host.layoutSubtreeIfNeeded()
        return host.fittingSize
    }

    /// Joins `parent` as a child window with its sharing type, collection
    /// behaviour and level, which orders the pill in with it.
    func attach(to parent: NSWindow) {
        panel.sharingType = parent.sharingType
        panel.collectionBehavior = parent.collectionBehavior
        panel.level = parent.level  // last
        parent.addChildWindow(panel, ordered: .above)
    }

    /// Keeps the pill at its sticker's level (Float on top switched).
    func setLevel(_ level: NSWindow.Level) {
        if panel.level != level { panel.level = level }
    }

    /// Places the pill for a sticker whose box is `stickerRect` on a display
    /// whose visible frame is `visibleFrame`.
    func place(around stickerRect: CGRect, visibleFrame: CGRect) {
        lastPlacement = (stickerRect, visibleFrame)
        let target = Self.frame(size: size, stickerRect: stickerRect, visibleFrame: visibleFrame)
        if panel.frame != target { panel.setFrame(target, display: true) }
    }

    /// Places the pill again after its size changed.
    func refit() {
        guard let lastPlacement else { return }
        place(around: lastPlacement.stickerRect, visibleFrame: lastPlacement.visibleFrame)
    }

    /// Removes the pill for good.
    func close() {
        model.cancel()
        model.onResize = nil
        panel.parent?.removeChildWindow(panel)
        panel.orderOut(nil)
        panel.close()
        panel.contentView = nil
    }
}
```

```swift
/// focus. Every display sits at x ≥ 40 000 pt, so panels ordered in never
/// appear on the desktop; `finish()` closes them (the pill too). A test

/// panels in and `finish()`.
@MainActor

    let store: LibraryStore
    let library: LibraryController
    let screens: FakeScreens
    let focus = RecordingFocus()
    let manager: StickerManager

    init(_ model: Library, displays: [DisplayInfo]) throws {

        store = LibraryStore(root: root)

        }

    /// Every sticker's master: 400 × 200 px.
    nonisolated static let master = Fixtures.image(width: 400, height: 200)

    /// A bitmap for `request`, rendered before any panel exists.
    static func render(_ request: RenderRequest) async throws -> RenderedSticker {
        try await StyleRenderer(masterProvider: { _ in master }).render(request)
    }

    func panel(_ id: UUID) throws -> StickerPanel {
        try #require(manager.panel(for: id))
    }

    func view(_ id: UUID) throws -> StickerView {
        try #require(manager.panel(for: id)?.contentView as? StickerView)
    }

    func editor() throws -> StickerEditor {
        try #require(manager.editor)
    }

    /// Ends editing of `id` (on the external display) the way `trigger`
    /// does. The external display's runtime ID is 3; `displayGone` unplugs it
    /// and runs the reconcile the display change schedules.
    func end(_ trigger: EditingEndTrigger, editing id: UUID) throws {
        switch trigger {
        case .escape: try view(id).keyDown(with: try Self.keyEvent(53, "\u{1b}"))
        case .resignKey: try panel(id).onResignKey?()
        case .sleepOrLock: manager.systemWillSleepOrLock()
        case .displayRemoved: manager.handleDisplayRemoved(displayID: 3)
        case .displayGone:
            screens.all = screens.all.filter { $0.uuid != Fixtures.externalUUID }
            manager.reconcileNow()
        case .rebuild: manager.rebuildAllPanels()
        }
    }

    func finish() {
        manager.closeAllPanels()
        try? FileManager.default.removeItem(at: root)
    }

    static func keyEvent(_ keyCode: UInt16, _ characters: String) throws -> NSEvent {
        try #require(NSEvent.keyEvent(with: .keyDown, location: .zero, modifierFlags: [], timestamp: 0,
                                      windowNumber: 0, context: nil, characters: characters,
                                      charactersIgnoringModifiers: characters, isARepeat: false, keyCode: keyCode))
    }
}
```

```swift
import AppKit
```

```swift
/// Where editing moves keyboard focus. Tests substitute a recorder, so they
/// never activate the app or make a panel key.
@MainActor
protocol EditingFocus: AnyObject {
    /// The frontmost app, unless it is Stickermine itself.
    func frontmostOtherApp() -> NSRunningApplication?
    /// Activates Stickermine and makes `panel` key with its content view as
    /// first responder, so Esc, Delete and trackpad gestures arrive.
    func takeFocus(for panel: NSPanel)
    /// Hands focus back to `app` once editing ends, but only while
    /// Stickermine is still frontmost and none of its other windows took key:
    /// a click into another app or onto one of Stickermine's windows keeps
    /// that focus. Without `app` (Stickermine itself was frontmost), another
    /// visible Stickermine window that can be key gets it back, else
    /// Stickermine deactivates.
    func returnFocus(to app: NSRunningApplication?)
}

@MainActor
final class LiveEditingFocus: EditingFocus {
    private static let log = Logger(subsystem: "com.ethan.stickermine", category: "editing")

    init() {}

    func frontmostOtherApp() -> NSRunningApplication? {
        let front = NSWorkspace.shared.frontmostApplication
        return front?.processIdentifier == ProcessInfo.processInfo.processIdentifier ? nil : front
    }

    func takeFocus(for panel: NSPanel) {
        NSApp.activate()
        panel.makeKey()
        if let view = panel.contentView { panel.makeFirstResponder(view) }
        // Activation of an accessory app is expected but unverified (spec
        // section 10); the log line says what happened.
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) { [weak panel] in
            MainActor.assumeIsolated {
                Self.log.notice("editing focus +0.5s: appActive=\(NSApp.isActive) key=\(panel?.isKeyWindow ?? false)")
            }
        }
    }

    func returnFocus(to app: NSRunningApplication?) {
        // On the next turn, when a click elsewhere has finished moving key status.
        DispatchQueue.main.async {
            MainActor.assumeIsolated {
                guard NSApp.isActive, NSApp.keyWindow == nil || NSApp.keyWindow is StickerPanel else {
                    let front = NSWorkspace.shared.frontmostApplication?.bundleIdentifier ?? "?"
                    Self.log.notice("focus stays with \(front, privacy: .public)")
                    return
                }
                if let app, !app.isTerminated {
                    app.activate()
                    Self.log.notice("focus returned to \(app.bundleIdentifier ?? "?", privacy: .public)")
                } else if let window = NSApp.windows.first(where: {
                    $0.isVisible && $0.canBecomeKey && !($0 is StickerPanel)
                }) {
                    window.makeKeyAndOrderFront(nil)
                    Self.log.notice("focus returned to \(window.title, privacy: .public)")
                } else {
                    NSApp.deactivate()
                    Self.log.notice("focus released")
                }
            }
        }
    }

/// One sticker being edited (spec section 10): the toolbar pill and the
/// keys. `StickerManager` creates it when editing begins and drops it when
/// editing ends; every model write goes through the manager.
@MainActor
final class StickerEditor {
    let placementID: UUID
    let panel: StickerPanel
    let view: StickerView
    /// The app that was frontmost before editing began.
    let previousApp: NSRunningApplication?
    let pill: ToolbarPill
    private unowned let manager: StickerManager

    init(placementID: UUID, panel: StickerPanel, view: StickerView, previousApp: NSRunningApplication?,
         target: StickerManager.EditTarget, renderer: StyleRenderer, manager: StickerManager) {
        self.placementID = placementID
        self.panel = panel
        self.view = view
        self.previousApp = previousApp
        self.manager = manager
        let model = ToolbarPillModel(placement: target.placement, natural: target.natural,
                                     sourceLongSide: target.sourceLongSide, renderer: renderer,
                                     backingScale: target.display.backingScale)
        pill = ToolbarPill(model: model)
        let id = placementID
        model.onStyle = { [weak manager] style in manager?.setStyle(style, for: id) }
        model.onFlip = { [weak manager] in manager?.toggleFlip(for: id) }
        model.onFloatOnTop = { [weak manager] in manager?.toggleOnTop(for: id) }
        model.onRemove = { [weak manager] in manager?.remove(placement: id) }
    }

    /// Takes the view's key events and shows the pill.
    func show() {
        view.onKeyDown = { [weak self] event in self?.keyDown(event) ?? false }
        pill.attach(to: panel)
        placePill()
    }

    /// Editing ended: the view's key events are let go and the pill goes.
    func tearDown() {
        view.onKeyDown = nil
        pill.close()
    }

    // MARK: Keys

    /// Esc ends editing; Delete removes the placement (on the next turn, so
    /// the panel isn't closed inside its own key event).
    func keyDown(_ event: NSEvent) -> Bool {
        switch event.keyCode {
        case 53:
            manager.endEditing(discardGesture: true)
            return true
        case 51, 117:
            manager.scheduleRemoval(of: placementID)
            return true
        default:
            return false
        }
    }

    // MARK: Pill

    /// The shown bitmap's box; the sticker rect before the first render.
    private func shownSize(_ target: StickerManager.EditTarget) -> CGSize {
        let content = view.contentPointSize
        return content.width > 0 && content.height > 0 ? content : target.layout.stickerRect.size
    }

    /// Places the pill under (or above) the sticker's current box, on the
    /// display under the box's centre (during a drag, the one it is over).
    func placePill() {
        guard let target = manager.editTarget(for: placementID) else { return }
        let box = StickerView.boundingSize(of: shownSize(target), scale: view.contentScale,
                                           rotation: view.contentRotation)
        let frame = panel.frame
        // The outline and the knob on its bottom-right corner reach this far past
        // the box: the pill keeps its gap from them, so it never covers the knob.
        let reach = StickerView.outlineOutset + StickerView.knobRadius
        let stickerRect = CGRect(x: frame.midX - box.width / 2, y: frame.midY - box.height / 2,
                                 width: box.width, height: box.height).insetBy(dx: 0, dy: -reach)
        let display = manager.display(at: NSPoint(x: frame.midX, y: frame.midY)) ?? target.display
        pill.place(around: stickerRect, visibleFrame: display.visibleFrame)
    }

    /// The placement was written or its window changed: the pill shows its
    /// style, flip and Float on top, keeps its level, and follows it.
    func placementDidChange() {
        guard let target = manager.editTarget(for: placementID) else { return }
        pill.model.update(style: target.placement.style, flipped: target.placement.flipped,
                          onTop: target.placement.onTop)
        pill.setLevel(panel.level)
        placePill()
    }
}
```

```swift
/// Where editing moves keyboard focus. Tests substitute a recorder, so they
/// never activate the app or make a panel key.
@MainActor
protocol EditingFocus: AnyObject {
    /// The frontmost app, unless it is Stickermine itself.
    func frontmostOtherApp() -> NSRunningApplication?
    /// Activates Stickermine and makes `panel` key with its content view as
    /// first responder, so Esc, Delete and trackpad gestures arrive.
    func takeFocus(for panel: NSPanel)
    /// Hands focus back to `app` once editing ends, but only while
    /// Stickermine is still frontmost and none of its other windows took key:
    /// a click into another app or onto one of Stickermine's windows keeps
    /// that focus. Without `app` (Stickermine itself was frontmost), another
    /// visible Stickermine window that can be key gets it back, else
    /// Stickermine deactivates.
    func returnFocus(to app: NSRunningApplication?)
}

@MainActor
final class LiveEditingFocus: EditingFocus {
    private static let log = Logger(subsystem: "com.ethan.stickermine", category: "editing")

    init() {}

    func frontmostOtherApp() -> NSRunningApplication? {
        let front = NSWorkspace.shared.frontmostApplication
        return front?.processIdentifier == ProcessInfo.processInfo.processIdentifier ? nil : front
    }

    func takeFocus(for panel: NSPanel) {
        NSApp.activate()
        panel.makeKey()
        if let view = panel.contentView { panel.makeFirstResponder(view) }
        // Activation of an accessory app is expected but unverified (spec
        // section 10); the log line says what happened.
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) { [weak panel] in
            MainActor.assumeIsolated {
                Self.log.notice("editing focus +0.5s: appActive=\(NSApp.isActive) key=\(panel?.isKeyWindow ?? false)")
            }
        }
    }

    func returnFocus(to app: NSRunningApplication?) {
        // On the next turn, when a click elsewhere has finished moving key status.
        DispatchQueue.main.async {
            MainActor.assumeIsolated {
                guard NSApp.isActive, NSApp.keyWindow == nil || NSApp.keyWindow is StickerPanel else {
                    let front = NSWorkspace.shared.frontmostApplication?.bundleIdentifier ?? "?"
                    Self.log.notice("focus stays with \(front, privacy: .public)")
                    return
                }
                if let app, !app.isTerminated {
                    app.activate()
                    Self.log.notice("focus returned to \(app.bundleIdentifier ?? "?", privacy: .public)")
                } else if let window = NSApp.windows.first(where: {
                    $0.isVisible && $0.canBecomeKey && !($0 is StickerPanel)
                }) {
                    window.makeKeyAndOrderFront(nil)
                    Self.log.notice("focus returned to \(window.title, privacy: .public)")
                } else {
                    NSApp.deactivate()
                    Self.log.notice("focus released")
                }
            }
        }
    }

/// One sticker being edited (spec section 10): the toolbar pill, keys, the
/// drag, the corner knob and trackpad pinch and rotate. `StickerManager`
/// creates it when editing begins and drops it when editing ends; every
/// model write goes through the manager.
///
/// Gesture lifecycle: the first gesture to begin grows the window once to a
/// square that fits the sticker turned any way at up to twice its size
/// (`EditGeometry.gestureSide`), and the manager holds the frame. Every event
/// only changes the content layer's transform (scale and rotation around the
/// centre). When the last gesture ends, the manager writes the new pose and
/// rotation, renders the bitmap with them baked in, and then shrinks the
/// window and resets the transform in one step.
@MainActor
final class StickerEditor {
    enum Gesture: Hashable {
        case knob, magnify, rotate
    }

    /// What the current gesture started from.
    struct GestureBase: Equatable {
        /// The window's centre: the gesture scales and rotates around it.
        let center: CGPoint
        /// The shown bitmap's box (rotated, rim included) at the start.
        let contentSize: CGSize
        let margin: CGFloat
        /// The pose scale on this display at the start.
        let poseScale: Double
        /// The placement's rotation at the start.
        let rotation: Double
        let limits: ClosedRange<Double>
    }

    let placementID: UUID
    let panel: StickerPanel
    let view: StickerView
    /// The app that was frontmost before editing began.
    let previousApp: NSRunningApplication?
    let pill: ToolbarPill
    private unowned let manager: StickerManager
    private let log = Logger(subsystem: "com.ethan.stickermine", category: "editing")

    private(set) var activeGestures: Set<Gesture> = []
    private(set) var base: GestureBase?
    /// The live change: a factor on `base.poseScale` and a rotation to add.
    private(set) var scaleFactor: Double = 1
    private(set) var rotationDelta: Double = 0
    /// Window resizes since the current gesture began (one, unless the
    /// sticker outgrows the square).
    private(set) var gestureResizeCount = 0
    private var knobStart: (vector: CGVector, scale: Double, rotation: Double)?

    init(placementID: UUID, panel: StickerPanel, view: StickerView, previousApp: NSRunningApplication?,
         target: StickerManager.EditTarget, renderer: StyleRenderer, manager: StickerManager) {
        self.placementID = placementID
        self.panel = panel
        self.view = view
        self.previousApp = previousApp
        self.manager = manager
        let model = ToolbarPillModel(placement: target.placement, natural: target.natural,
                                     sourceLongSide: target.sourceLongSide, renderer: renderer,
                                     backingScale: target.display.backingScale)
        pill = ToolbarPill(model: model)
        let id = placementID
        model.onStyle = { [weak manager] style in manager?.setStyle(style, for: id) }
        model.onFlip = { [weak manager] in manager?.toggleFlip(for: id) }
        model.onFloatOnTop = { [weak manager] in manager?.toggleOnTop(for: id) }
        model.onRemove = { [weak manager] in manager?.remove(placement: id) }
    }

    var isGestureActive: Bool { !activeGestures.isEmpty }

    /// Takes the view's editing events (keys, gestures, the knob) and shows
    /// the pill.
    func show() {
        view.onKeyDown = { [weak self] event in self?.keyDown(event) ?? false }
        view.onMagnify = { [weak self] event in
            self?.magnify(by: Double(event.magnification), phase: event.phase)
        }
        view.onRotate = { [weak self] event in
            self?.rotate(byDegrees: Double(event.rotation), phase: event.phase)
        }
        view.onKnobDrag = { [weak self] phase, point, shift in self?.knob(phase, at: point, snapping: shift) }
        pill.attach(to: panel)
        placePill()
    }

    /// Editing ended: the view's editing events are let go, the pill goes and
    /// any gesture is forgotten (the manager resets the transform and frame).
    func tearDown() {
        view.onKeyDown = nil
        view.onMagnify = nil
        view.onRotate = nil
        view.onKnobDrag = nil
        activeGestures = []
        base = nil
        knobStart = nil
        pill.close()
    }

    // MARK: Keys

    /// Esc ends editing; Delete removes the placement (on the next turn, so
    /// the panel isn't closed inside its own key event).
    func keyDown(_ event: NSEvent) -> Bool {
        switch event.keyCode {
        case 53:
            manager.endEditing(discardGesture: true)
            return true
        case 51, 117:
            manager.scheduleRemoval(of: placementID)
            return true
        default:
            return false
        }
    }

    // MARK: Gestures

    /// A trackpad pinch: `amount` is the event's magnification (1 + amount
    /// multiplies the size).
    func magnify(by amount: Double, phase: NSEvent.Phase) {
        handle(.magnify, phase: phase) { (scaleFactor * (1 + amount), rotationDelta) }
    }

    /// A trackpad rotation: `degrees` counter-clockwise.
    func rotate(byDegrees degrees: Double, phase: NSEvent.Phase) {
        handle(.rotate, phase: phase) { (scaleFactor, rotationDelta + degrees * Double.pi / 180) }
    }

    /// A drag on the corner knob: scale and rotate around the centre so the
    /// knob follows the cursor (`point`, screen coordinates); Shift snaps the
    /// rotation to 15°.
    func knob(_ phase: StickerView.DragPhase, at point: CGPoint, snapping: Bool) {
        switch phase {
        case .began:
            guard beginGesture(.knob), let base else { return }
            knobStart = (CGVector(dx: point.x - base.center.x, dy: point.y - base.center.y), scaleFactor, rotationDelta)
        case .moved:
            followKnob(to: point, snapping: snapping)
        case .ended:
            followKnob(to: point, snapping: snapping)
            endGesture(.knob)
        }
    }

    private func followKnob(to point: CGPoint, snapping: Bool) {
        guard activeGestures.contains(.knob), let base, let start = knobStart else { return }
        let change = EditGeometry.knobChange(
            from: start.vector, to: CGVector(dx: point.x - base.center.x, dy: point.y - base.center.y),
            baseRotation: base.rotation + start.rotation, snap: snapping)
        apply(scale: start.scale * change.scale, rotation: start.rotation + change.rotation)
    }

    private func handle(_ kind: Gesture, phase: NSEvent.Phase, change: () -> (Double, Double)) {
        if phase.contains(.ended) || phase.contains(.cancelled) {
            endGesture(kind)
            return
        }
        guard beginGesture(kind) else { return }
        let (scale, rotation) = change()
        apply(scale: scale, rotation: rotation)
        // An event without phases is a whole gesture on its own.
        if phase.isEmpty { endGesture(kind) }
    }

    /// The first gesture grows the window once; later ones join it.
    private func beginGesture(_ kind: Gesture) -> Bool {
        if activeGestures.contains(kind) { return true }
        if activeGestures.isEmpty {
            guard let target = manager.editTarget(for: placementID), target.layout.pose.scale > 0,
                  manager.holdFrame(for: placementID)
            else { return false }
            let start = GestureBase(
                center: CGPoint(x: panel.frame.midX, y: panel.frame.midY), contentSize: shownSize(target),
                margin: view.windowMargin, poseScale: target.layout.pose.scale, rotation: target.placement.rotation,
                limits: EditGeometry.scaleLimits(natural: target.natural, displaySize: target.display.frame.size))
            base = start
            scaleFactor = 1
            rotationDelta = 0
            gestureResizeCount = 0
            resizeWindow(factor: max(1, min(EditGeometry.gestureHeadroom, maximumFactor(start))))
        }
        activeGestures.insert(kind)
        return true
    }

    /// The largest factor the limits allow from the gesture's start.
    private func maximumFactor(_ base: GestureBase) -> Double {
        max(base.limits.upperBound, base.poseScale) / base.poseScale
    }

    private func apply(scale proposed: Double, rotation: Double) {
        guard let base else { return }
        let total = EditGeometry.clampedScale(base.poseScale * proposed, current: base.poseScale, limits: base.limits)
        scaleFactor = total / base.poseScale
        rotationDelta = EditGeometry.normalized(rotation)
        let needed = EditGeometry.gestureSide(contentSize: base.contentSize, factor: scaleFactor, margin: base.margin)
        if needed > panel.frame.width {
            // Outgrew the square: grow again, with room to spare.
            resizeWindow(factor: min(maximumFactor(base), scaleFactor * 1.5))
        }
        view.setContentTransform(scale: CGFloat(scaleFactor), rotation: CGFloat(rotationDelta))
        placePill()
    }

    private func resizeWindow(factor: Double) {
        guard let base else { return }
        let side = EditGeometry.gestureSide(contentSize: base.contentSize, factor: factor, margin: base.margin)
        let square = NSRect(x: base.center.x - side / 2, y: base.center.y - side / 2, width: side, height: side)
        panel.setFrame(panel.backingAlignedRect(square, options: .alignAllEdgesOutward), display: true)
        gestureResizeCount += 1
    }

    private func endGesture(_ kind: Gesture) {
        guard activeGestures.remove(kind) != nil else { return }
        if kind == .knob { knobStart = nil }
        guard activeGestures.isEmpty else { return }
        base = nil
        log.notice("gesture end: scale ×\(self.scaleFactor) rotation \(self.rotationDelta)")
        manager.commitGesture(placement: placementID, scaleFactor: scaleFactor, rotationDelta: rotationDelta)
    }

    // MARK: Pill

    /// The shown bitmap's box; the sticker rect before the first render.
    private func shownSize(_ target: StickerManager.EditTarget) -> CGSize {
        let content = view.contentPointSize
        return content.width > 0 && content.height > 0 ? content : target.layout.stickerRect.size
    }

    /// Places the pill under (or above) the sticker's current box, on the
    /// display under the box's centre (during a drag, the one it is over).
    func placePill() {
        guard let target = manager.editTarget(for: placementID) else { return }
        let box = StickerView.boundingSize(of: shownSize(target), scale: view.contentScale,
                                           rotation: view.contentRotation)
        let frame = panel.frame
        // The outline and the knob on its bottom-right corner reach this far past
        // the box: the pill keeps its gap from them, so it never covers the knob.
        let reach = StickerView.outlineOutset + StickerView.knobRadius
        let stickerRect = CGRect(x: frame.midX - box.width / 2, y: frame.midY - box.height / 2,
                                 width: box.width, height: box.height).insetBy(dx: 0, dy: -reach)
        let display = manager.display(at: NSPoint(x: frame.midX, y: frame.midY)) ?? target.display
        pill.place(around: stickerRect, visibleFrame: display.visibleFrame)
    }

    /// The placement was written or its window changed: the pill shows its
    /// style, flip and Float on top, keeps its level, and follows it.
    func placementDidChange() {
        guard let target = manager.editTarget(for: placementID) else { return }
        pill.model.update(style: target.placement.style, flipped: target.placement.flipped,
                          onTop: target.placement.onTop)
        pill.setLevel(panel.level)
        placePill()
    }
}
```

```swift
@MainActor
```

```swift
    func frontmostOtherApp() -> NSRunningApplication?

    /// first responder, so Esc, Delete and trackpad gestures arrive.

    /// that focus. Without `app` (Stickermine itself was frontmost), another
    /// visible Stickermine window that can be key gets it back, else
    /// Stickermine deactivates.

/// One sticker being edited (spec section 10): the toolbar pill, keys, the
/// drag, the corner knob and trackpad pinch and rotate. `StickerManager`
/// creates it when editing begins and drops it when editing ends; every
/// model write goes through the manager.
///
/// Gesture lifecycle: the first gesture to begin grows the window once to a
/// square that fits the sticker turned any way at up to twice its size
/// (`EditGeometry.gestureSide`), and the manager holds the frame. Every event
/// only changes the content layer's transform (scale and rotation around the
/// centre). When the last gesture ends, the manager writes the new pose and
/// rotation, renders the bitmap with them baked in, and then shrinks the
/// window and resets the transform in one step.
///
/// A drag moves the window with the mouse, event by event, while the manager
/// holds the frame; the pill follows each step. At the mouse-up the manager
/// writes the new position, or a placement on the display under the centre.
@MainActor
final class StickerEditor {
    enum Gesture: Hashable {
        case knob, magnify, rotate
    }

    /// What the current gesture started from.
    struct GestureBase: Equatable {
        /// The window's centre: the gesture scales and rotates around it.
        let center: CGPoint
        /// The shown bitmap's box (rotated, rim included) at the start.
        let contentSize: CGSize
        let margin: CGFloat
        /// The pose scale on this display at the start.
        let poseScale: Double
        /// The placement's rotation at the start.
        let rotation: Double
        let limits: ClosedRange<Double>
    }

    let placementID: UUID
    let panel: StickerPanel
    let view: StickerView
    /// The app that was frontmost before editing began.
    let previousApp: NSRunningApplication?
    let pill: ToolbarPill
    private unowned let manager: StickerManager
    private let log = Logger(subsystem: "com.ethan.stickermine", category: "editing")

    private(set) var activeGestures: Set<Gesture> = []
    private(set) var base: GestureBase?
    /// The live change: a factor on `base.poseScale` and a rotation to add.
    private(set) var scaleFactor: Double = 1
    private(set) var rotationDelta: Double = 0
    /// Window resizes since the current gesture began (one, unless the
    /// sticker outgrows the square).
    private(set) var gestureResizeCount = 0
    private var knobStart: (vector: CGVector, scale: Double, rotation: Double)?
    /// The window's origin minus the cursor at the drag's mouse-down.
    private(set) var dragOffset: CGVector?

    init(placementID: UUID, panel: StickerPanel, view: StickerView, previousApp: NSRunningApplication?,
         target: StickerManager.EditTarget, renderer: StyleRenderer, manager: StickerManager) {
        self.placementID = placementID
        self.panel = panel
        self.view = view
        self.previousApp = previousApp
        self.manager = manager
        let model = ToolbarPillModel(placement: target.placement, natural: target.natural,
                                     sourceLongSide: target.sourceLongSide, renderer: renderer,
                                     backingScale: target.display.backingScale)
        pill = ToolbarPill(model: model)
        let id = placementID
        model.onStyle = { [weak manager] style in manager?.setStyle(style, for: id) }
        model.onFlip = { [weak manager] in manager?.toggleFlip(for: id) }
        model.onFloatOnTop = { [weak manager] in manager?.toggleOnTop(for: id) }
        model.onRemove = { [weak manager] in manager?.remove(placement: id) }
    }

    var isGestureActive: Bool { !activeGestures.isEmpty }

    /// Takes the view's editing events (keys, gestures, the knob, drags) and
    /// shows the pill.
    func show() {
        view.onKeyDown = { [weak self] event in self?.keyDown(event) ?? false }
        view.onMagnify = { [weak self] event in
            self?.magnify(by: Double(event.magnification), phase: event.phase)
        }
        view.onRotate = { [weak self] event in
            self?.rotate(byDegrees: Double(event.rotation), phase: event.phase)
        }
        view.onKnobDrag = { [weak self] phase, point, shift in self?.knob(phase, at: point, snapping: shift) }
        view.onMoveDrag = { [weak self] phase, point in self?.drag(phase, at: point) }
        pill.attach(to: panel)
        placePill()
    }

    /// Editing ended: the view's editing events are let go, the pill goes and
    /// any gesture is forgotten (the manager resets the transform and frame).
    func tearDown() {
        view.onKeyDown = nil
        view.onMagnify = nil
        view.onRotate = nil
        view.onKnobDrag = nil
        view.onMoveDrag = nil
        activeGestures = []
        base = nil
        knobStart = nil
        dragOffset = nil
        pill.close()
    }

    // MARK: Keys

    /// Esc ends editing; Delete removes the placement (on the next turn, so
    /// the panel isn't closed inside its own key event).
    func keyDown(_ event: NSEvent) -> Bool {
        switch event.keyCode {
        case 53:
            manager.endEditing(discardGesture: true)
            return true
        case 51, 117:
            manager.scheduleRemoval(of: placementID)
            return true
        default:
            return false
        }
    }

    // MARK: Drag

    var isDragging: Bool { dragOffset != nil }

    /// A drag that started away from the knob: the window follows the cursor
    /// (`point`, screen coordinates) and the pill follows the window. At the
    /// mouse-up the manager writes the new position (or a placement on another
    /// display). Ignored while a gesture runs or settles.
    func drag(_ phase: StickerView.DragPhase, at point: CGPoint) {
        switch phase {
        case .began:
            guard !isGestureActive, !isDragging, manager.holdFrame(for: placementID) else { return }
            dragOffset = CGVector(dx: panel.frame.minX - point.x, dy: panel.frame.minY - point.y)
        case .moved:
            follow(point)
        case .ended:
            guard isDragging else { return }
            follow(point)
            dragOffset = nil
            manager.commitDrag(placement: placementID)
            placePill()
        }
    }

    private func follow(_ point: CGPoint) {
        guard let offset = dragOffset else { return }
        panel.setFrameOrigin(NSPoint(x: point.x + offset.dx, y: point.y + offset.dy))
        placePill()
    }

    // MARK: Gestures

    /// A trackpad pinch: `amount` is the event's magnification (1 + amount
    /// multiplies the size).
    func magnify(by amount: Double, phase: NSEvent.Phase) {
        handle(.magnify, phase: phase) { (scaleFactor * (1 + amount), rotationDelta) }
    }

    /// A trackpad rotation: `degrees` counter-clockwise.
    func rotate(byDegrees degrees: Double, phase: NSEvent.Phase) {
        handle(.rotate, phase: phase) { (scaleFactor, rotationDelta + degrees * Double.pi / 180) }
    }

    /// A drag on the corner knob: scale and rotate around the centre so the
    /// knob follows the cursor (`point`, screen coordinates); Shift snaps the
    /// rotation to 15°.
    func knob(_ phase: StickerView.DragPhase, at point: CGPoint, snapping: Bool) {
        switch phase {
        case .began:
            guard beginGesture(.knob), let base else { return }
            knobStart = (CGVector(dx: point.x - base.center.x, dy: point.y - base.center.y), scaleFactor, rotationDelta)
        case .moved:
            followKnob(to: point, snapping: snapping)
        case .ended:
            followKnob(to: point, snapping: snapping)
            endGesture(.knob)
        }
    }

    private func followKnob(to point: CGPoint, snapping: Bool) {
        guard activeGestures.contains(.knob), let base, let start = knobStart else { return }
        let change = EditGeometry.knobChange(
            from: start.vector, to: CGVector(dx: point.x - base.center.x, dy: point.y - base.center.y),
            baseRotation: base.rotation + start.rotation, snap: snapping)
        apply(scale: start.scale * change.scale, rotation: start.rotation + change.rotation)
    }

    private func handle(_ kind: Gesture, phase: NSEvent.Phase, change: () -> (Double, Double)) {
        if phase.contains(.ended) || phase.contains(.cancelled) {
            endGesture(kind)
            return
        }
        guard beginGesture(kind) else { return }
        let (scale, rotation) = change()
        apply(scale: scale, rotation: rotation)
        // An event without phases is a whole gesture on its own.
        if phase.isEmpty { endGesture(kind) }
    }

    /// The first gesture grows the window once; later ones join it. None
    /// starts during a drag.
    private func beginGesture(_ kind: Gesture) -> Bool {
        if activeGestures.contains(kind) { return true }
        guard !isDragging else { return false }
        if activeGestures.isEmpty {
            guard let target = manager.editTarget(for: placementID), target.layout.pose.scale > 0,
                  manager.holdFrame(for: placementID)
            else { return false }
            let start = GestureBase(
                center: CGPoint(x: panel.frame.midX, y: panel.frame.midY), contentSize: shownSize(target),
                margin: view.windowMargin, poseScale: target.layout.pose.scale, rotation: target.placement.rotation,
                limits: EditGeometry.scaleLimits(natural: target.natural, displaySize: target.display.frame.size))
            base = start
            scaleFactor = 1
            rotationDelta = 0
            gestureResizeCount = 0
            resizeWindow(factor: max(1, min(EditGeometry.gestureHeadroom, maximumFactor(start))))
        }
        activeGestures.insert(kind)
        return true
    }

    /// The largest factor the limits allow from the gesture's start.
    private func maximumFactor(_ base: GestureBase) -> Double {
        max(base.limits.upperBound, base.poseScale) / base.poseScale
    }

    private func apply(scale proposed: Double, rotation: Double) {
        guard let base else { return }
        let total = EditGeometry.clampedScale(base.poseScale * proposed, current: base.poseScale, limits: base.limits)
        scaleFactor = total / base.poseScale
        rotationDelta = EditGeometry.normalized(rotation)
        let needed = EditGeometry.gestureSide(contentSize: base.contentSize, factor: scaleFactor, margin: base.margin)
        if needed > panel.frame.width {
            // Outgrew the square: grow again, with room to spare.
            resizeWindow(factor: min(maximumFactor(base), scaleFactor * 1.5))
        }
        view.setContentTransform(scale: CGFloat(scaleFactor), rotation: CGFloat(rotationDelta))
        placePill()
    }

    private func resizeWindow(factor: Double) {
        guard let base else { return }
        let side = EditGeometry.gestureSide(contentSize: base.contentSize, factor: factor, margin: base.margin)
        let square = NSRect(x: base.center.x - side / 2, y: base.center.y - side / 2, width: side, height: side)
        panel.setFrame(panel.backingAlignedRect(square, options: .alignAllEdgesOutward), display: true)
        gestureResizeCount += 1
    }

    private func endGesture(_ kind: Gesture) {
        guard activeGestures.remove(kind) != nil else { return }
        if kind == .knob { knobStart = nil }
        guard activeGestures.isEmpty else { return }
        base = nil
        log.notice("gesture end: scale ×\(self.scaleFactor) rotation \(self.rotationDelta)")
        manager.commitGesture(placement: placementID, scaleFactor: scaleFactor, rotationDelta: rotationDelta)
    }

    // MARK: Pill

    /// The shown bitmap's box; the sticker rect before the first render.
    private func shownSize(_ target: StickerManager.EditTarget) -> CGSize {
        let content = view.contentPointSize
        return content.width > 0 && content.height > 0 ? content : target.layout.stickerRect.size
    }

    /// Places the pill under (or above) the sticker's current box, on the
    /// display under the box's centre (during a drag, the one it is over).
    func placePill() {
        guard let target = manager.editTarget(for: placementID) else { return }
        let box = StickerView.boundingSize(of: shownSize(target), scale: view.contentScale,
                                           rotation: view.contentRotation)
        let frame = panel.frame
        // The outline and the knob on its bottom-right corner reach this far past
        // the box: the pill keeps its gap from them, so it never covers the knob.
        let reach = StickerView.outlineOutset + StickerView.knobRadius
        let stickerRect = CGRect(x: frame.midX - box.width / 2, y: frame.midY - box.height / 2,
                                 width: box.width, height: box.height).insetBy(dx: 0, dy: -reach)
        let display = manager.display(at: NSPoint(x: frame.midX, y: frame.midY)) ?? target.display
        pill.place(around: stickerRect, visibleFrame: display.visibleFrame)
    }

    /// The placement was written or its window changed: the pill shows its
    /// style, flip and Float on top, keeps its level, and follows it.
    func placementDidChange() {
        guard let target = manager.editTarget(for: placementID) else { return }
        pill.model.update(style: target.placement.style, flipped: target.placement.flipped,
                          onTop: target.placement.onTop)
        pill.setLevel(panel.level)
        placePill()
    }
}
```
