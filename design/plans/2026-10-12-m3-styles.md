# M3 Sticker Styles and Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the four styles real. Puffy is a glossy, inflated die-cut sticker lit from the top-left; Outline has a thick white die-cut rim; Shadow and None are halo-free cutouts. Every style except None gets a Core Animation drop shadow that never catches clicks, in a window padded just enough for it. Bitmaps render off the main thread into IOSurface (or CGImage) contents in the capture's colour space, at the on-screen pixel size capped at 2048 px, with faint alpha cleared, and re-render when a window's backing scale changes. A `-styleGallery` debug run writes every style of Maple and of generated test shapes to PNGs for review, and `-debugPlaceMaple all` puts all four styles on the desktop.

**Architecture:** `StyleRecipes` (new, pure Core Image) builds each style's image graph in bitmap pixels: place the master (scale, flip, rotate), the white silhouette, the signed-distance rim with optional closing, Outline's composite and None's edge choke. `PuffyKernel` (new) holds the Puffy kernel's Metal source as a Swift string, compiles it once (off the main thread, through `StyleRenderer.prewarm()`), shades the rimmed cutout with it, and falls back to built-in filters (then to the plain rim) when compiling fails; it also measures a master's inscribed radius once per sticker. `StyleRenderer` keeps its M2 contract but replaces the baseline: one serial render queue, one Metal-backed `CIContext` plus an RGBAf one for Puffy, output into a tagged IOSurface (or a CGImage), one pass that clears alpha below 5/255 and builds the `AlphaMask`, `clearCaches()` after each bake. Outline and Puffy bitmaps grow by the rim's reach, so the subject keeps its size in every style. `StickerView.show` turns the style parameters into a layer shadow in points and a frame margin of `StyleParameters.shadowMargin` pixels over the backing scale, and reports backing-scale changes; `StickerManager` passes the on-screen parameters on commit, centres the bitmap's box plus margin on the sticker rect, and re-renders when a panel's backing scale changes. `StyleGallery` (new, debug) and an extended `DebugMaple` make the result visible.

**Tech Stack:** Swift 5 language mode, Core Image (built-in filters including `CISignedDistanceGradientFromRedMask`, plus one Metal Core Image kernel compiled at runtime with `CIKernel.kernels(withMetalString:)`), Metal (device only), IOSurface, Core Animation layer shadows, AppKit, ImageIO, Swift Testing, `xcodebuild` (Xcode 27 beta locally, Xcode 26.6 on CI).

**Spec:** `design/specs/2026-10-12-stickermine-v1-design.md`. This milestone implements section 8 in full (all four style recipes, parameter scaling per 800 px, the shared Metal-backed context plus the RGBAf Puffy context, a `CIFilter` per render, `clearCaches()` after a bake, the Puffy kernel as a string compiled once off the main thread with its built-in fallback, the layer shadow instead of baked pixels, the alpha clamp below about 0.02) and the rendering parts of section 9 (the frame as the bitmap's box plus a symmetric shadow margin of ceil(3 × radius) + |offset|, backing-aligned and zero for None; IOSurface contents rendered with `CIContext.render(_:to:bounds:colorSpace:)` in the capture's colour space and tagged with `kIOSurfaceColorSpace`, with the CGImage fallback chosen by the spike; the 2048 px memory cap), plus section 11's "Backing scale changes: re-render the bitmap (`windowDidChangeBackingProperties`)" and section 18's style-parameter unit tests. The plan index with the Interface Contract is `design/plans/2026-10-12-stickermine-v1-plan.md`; the M1 and M2 plans are `design/plans/2026-10-12-m1-foundation.md` and `design/plans/2026-10-12-m2-model-displays.md`.

## Contract changes

Signature and meaning changes (every call site in M1/M2 code is updated in this plan):

1. **`RenderedSticker` gains `let backingScale: CGFloat`**, its last stored property, so the memberwise initializer takes `backingScale:` last. `StickerView.show` turns the style parameters (pixels) into a layer shadow (points) with the scale the bitmap was rendered for, instead of whatever screen the window is on at that moment (M2's notes said "divided by the panel's backing scale"; for a committed render the two are equal, and a window that changes scale is re-rendered). Task 5 updates the one test that builds a `RenderedSticker` by hand.
2. **For Outline and Puffy, `RenderedSticker.pointBounds` now includes the white rim.** The bitmap is the subject at its on-screen size plus the rim's reach (`StyleParameters.rimReach(for:)`: ceil(r) + 1 px at the on-screen size) on every side, then rotated. Drawing the rim inside the old box would shrink the subject: by about 3% on most stickers, but by a third on a thin 10:1 capture (seen in the gallery while writing this plan). A die-cut border goes around the subject, and switching styles never changes the subject's size. Spec section 9 holds as written: the frame is the bitmap's box plus a symmetric shadow margin, and the pose centre is the bitmap's centre. Clamping and display ownership keep using `StickerGeometry.Layout.stickerRect` (the subject's rotated box). `StickerManager.applyFrame` now centres the shown bitmap's box on the sticker rect (Task 7); before the first render it uses the sticker rect, as in M2. M2's `StickerManagerTests.onlyTheNewestRenderIsShown` and `aPanelRecreatedForSharingKeepsItsBitmap` expect the old size and are updated in Task 5.
3. **`StyleRenderer.init(masterProvider:options: Options = .standard)`.** The contract's `init(masterProvider:)` call still compiles. The options choose IOSurface or CGImage contents (the spike decision), the rim's closing, and force Puffy's fallback (tests and the gallery).
4. **`StickerView.showContents(_:pointSize:shadow:frameMargin: CGFloat? = nil)`**: M1's primitive gains a defaulted `frameMargin`, so `show` can pass `StyleParameters.shadowMargin` in points and M2's sharing-type recreation (`setSharingHidden`) can carry a panel's margin over. Existing calls compile unchanged.
5. **`StyleRenderer.renderBaseline(master:request:)` is removed** (M2's notes: M3 replaces the per-style drawing). `canvas(for:)` keeps its signature and its 2048 px cap, and now adds the rim's reach. `clampAlphaAndBuildMask(pixels:width:height:)` is kept and gains an overload with `rowBytes:` for IOSurface row padding.

Deviations from the spec's wording, all within its intent:

- Puffy's inscribed radius is "computed once at master resolution and scaled linearly with size": it is measured once per sticker, on a copy of the master at most 1024 px long, because `CISignedDistanceGradientFromRedMask` caps its distance at 1000 px. It is cached per sticker ID.
- The built-in Puffy fallback uses one blur (σ = 2R/3) as its height, so it never sums images, and a tent-shaped specular instead of a power curve; a linearised Blinn-Phong saturated into a white wash in the gallery. It is still "Sobel gradients + Lambert colour matrix + screen-blended specular".
- The layer shadow stays unrasterized, one of the two options spec section 8 allows.
- "On a background task" is one serial dispatch queue, so launch with many stickers never runs dozens of GPU renders at once.

## Global Constraints

All constraints in the index apply. Milestone-specific ones, verbatim from the spec:

- "`StyleRenderer` produces one bitmap for (master cutout, style, flip, rotation, scale, backing scale factor) on a background task with one shared Metal-backed `CIContext` (plus an RGBAf context for Puffy). Create a `CIFilter` per render (not thread-safe); call `clearCaches()` after a bake." (section 8)
- "height = mean of Gaussian blurs of the rim mask at σ = R/3, 2R/3, R, averaged explicitly inside the kernel (not through `CIAdditionCompositing`, which breaks if an intermediate is 8-bit)" (section 8)
- "The kernel source is a Swift string literal in `PuffyKernel.swift`: no `.metal` files go in the target, because compiling them needs the separately downloaded Metal Toolchain. Compile once at launch off the main thread. If compilation throws, fall back to a built-in-filter Puffy (Sobel gradients + Lambert colour matrix + screen-blended specular)." (section 8)
- "**The drop shadow is a `CALayer` shadow, not baked pixels.** A blurred shadow baked into the bitmap would catch clicks across its whole faint tail; a layer shadow doesn't." … "Baked bitmaps also clamp alpha below about 0.02 to 0, so faint fringes don't catch clicks." (section 8)
- "**Frame:** the bitmap's bounding box plus a symmetric shadow margin of ceil(3 × shadow radius) + |shadow offset| on every side, backing-aligned (zero margin for None). The pose centre is the bitmap's centre, which is also the window's centre. Clamping and display ownership use the sticker rect, never the padded window rect." (section 9)
- "Contents are preferably IOSurface-backed (about 1× the bitmap's bytes instead of about 2× for a `CGImage`): render with `CIContext.render(_:to:bounds:colorSpace:)` in the capture's colour space and tag the surface with `kIOSurfaceColorSpace`. Fall back to `CGImage` contents if the spike shows a colour shift or broken alpha hit-testing with IOSurface contents." (section 9)
- "**Memory:** the bitmap is rendered at the on-screen pixel size, capped at 2048 px on the long side (above that, the layer scales the bitmap up)." (section 9)
- "**Backing scale changes:** re-render the bitmap (`windowDidChangeBackingProperties`); the scale factor isn't part of the layout key." (section 11)
- From M2, unchanged: every display a test builds sits at x ≥ 40 000 pt, off every real screen, and every test that orders a panel in closes it before it suspends or returns, so the test host never shows a window. `StyleRenderer.swift`, `StyleRecipes.swift`, `PuffyKernel.swift`, `StyleParameters.swift` and `SurfaceContents.swift` never import AppKit or SwiftUI (`LibraryModelTests.pureLogicFilesStayFreeOfAppKit`, extended in Task 8).
- As in M1 and M2: run every command from the repository root (`/Users/ethan/Developer/stickermine`) in bash or zsh, not fish. The test command is `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer xcodebuild test -project Stickermine.xcodeproj -scheme Stickermine -destination 'platform=macOS,arch=arm64' -derivedDataPath build/DerivedData`, with `-only-testing:StickermineTests/<Suite>` for one suite.
```swift
import Foundation

/// Style parameters in pixels, scaled linearly with the sticker's pixel size
/// from the spec's values per 800 px (spec section 8). Pure math: the style
/// recipes, the layer shadow and the window margin read these.
struct StyleParameters: Equatable {
    /// Outline/Puffy white rim radius r (12 px per 800).
    let rimRadius: Double
    /// SDF closing distance s for a smoother die-cut line (10 px per 800).
    let closing: Double
    /// Layer-shadow blur radius (10 px per 800).
    let shadowRadius: Double
    /// Downward layer-shadow offset (0.6 × the radius).
    let shadowOffset: Double
    /// Layer-shadow opacity (0.35 at every size).
    let shadowOpacity: Double
    /// None's edge choke blur σ = 0.5 × (source long side / 512), in the
    /// source's (master's) pixels.
    let chokeSigma: Double

    static let referenceLongSide = 800.0
    static let rimRadiusPerReference = 12.0
    static let closingPerReference = 10.0
    static let shadowRadiusPerReference = 10.0
    static let shadowOffsetPerRadius = 0.6
    static let shadowOpacityValue = 0.35
    static let chokeSigmaPer512 = 0.5
    /// Puffy's dome radius R = clamp(0.5 × inscribed radius, 6, 300) per 800 px.
    static let domeRadiusPerInscribed = 0.5
    static let domeRadiusMinPerReference = 6.0
    static let domeRadiusMaxPerReference = 300.0
    /// Puffy's dome height: heightPx = 0.9 × R.
    static let domeHeightPerRadius = 0.9

    /// `longSide`: the sticker's unrotated long side in pixels (points × scale ×
    /// backing scale, or the capped bitmap's). `sourceLongSide`: the master's
    /// long side in pixels.
    static func forStickerPixels(longSide: Double, sourceLongSide: Double) -> StyleParameters {
        let factor = max(longSide, 0) / referenceLongSide
        let shadowRadius = shadowRadiusPerReference * factor
        return StyleParameters(
            rimRadius: rimRadiusPerReference * factor,
            closing: closingPerReference * factor,
            shadowRadius: shadowRadius,
            shadowOffset: shadowOffsetPerRadius * shadowRadius,
            shadowOpacity: shadowOpacityValue,
            chokeSigma: chokeSigmaPer512 * max(sourceLongSide, 0) / 512
        )
    }

    /// The transparent padding on every side of the sticker's window, in
    /// pixels: ceil(3 × shadow radius) + |offset|, and 0 for None, which has no
    /// shadow (spec section 9).
    func shadowMargin(for style: StickerStyle) -> Double {
        switch style {
        case .none:
            return 0
        case .puffy, .outline, .shadow:
            return (3 * shadowRadius).rounded(.up) + abs(shadowOffset)
        }
    }

    /// How far the white rim reaches beyond the subject's edge, in pixels: the
    /// rim radius rounded up plus 1 px for the anti-aliased edge; 0 for the
    /// styles without a rim. A rimmed sticker's bitmap is this much larger on
    /// every side, so the subject keeps its size in every style.
    func rimReach(for style: StickerStyle) -> Double {
        switch style {
        case .puffy, .outline:
            return rimRadius.rounded(.up) + 1
        case .shadow, .none:
            return 0
        }
    }

    /// Puffy's dome radius R in pixels: clamp(0.5 × inscribed radius, 6, 300)
    /// per 800 px of `longSide`, so R grows linearly with the sticker's size
    /// (spec section 8). Both arguments in the same pixels.
    static func domeRadius(inscribedRadius: Double, longSide: Double) -> Double {
        let factor = max(longSide, 0) / referenceLongSide
        let wanted = domeRadiusPerInscribed * max(inscribedRadius, 0)
        return min(max(wanted, domeRadiusMinPerReference * factor), domeRadiusMaxPerReference * factor)
    }
}
```

```swift
import CoreGraphics
import CoreImage
import CoreVideo
import IOSurface

/// IOSurfaces for `CALayer.contents`. An IOSurface costs about 1× the bitmap's
/// bytes in the app; a CGImage as layer contents costs about 2× (spec section 9).
/// `StyleRenderer` renders into `blank(width:height:)` surfaces and tags them;
/// `make(from:)` converts an existing image.
enum SurfaceContents {
    private static let context = CIContext(options: [.cacheIntermediates: false])

    /// An empty BGRA, premultiplied surface (rows padded as IOSurface prefers;
    /// read `bytesPerRow`). nil for an empty size or when allocation fails.
    static func blank(width: Int, height: Int) -> IOSurface? {
        guard width > 0, height > 0 else { return nil }
        let properties: [IOSurfacePropertyKey: Any] = [
            .width: width,
            .height: height,
            .bytesPerElement: 4,
            .bytesPerRow: IOSurfaceAlignProperty(kIOSurfaceBytesPerRow, width * 4),
            .pixelFormat: kCVPixelFormatType_32BGRA,
        ]
        return IOSurface(properties: properties)
    }

    /// Tags `surface` with `colorSpace` (`kIOSurfaceColorSpace`), so Core
    /// Animation shows its pixels in that space instead of assuming sRGB.
    static func tag(_ surface: IOSurface, with colorSpace: CGColorSpace) {
        if let serialized = colorSpace.copyPropertyList() {
            IOSurfaceSetValue(surface, kIOSurfaceColorSpace, serialized)
        }
    }

    /// The colour space a BGRA surface of `image` uses: the image's own when it
    /// is RGB, sRGB otherwise (a BGRA surface can only hold RGB).
    static func colorSpace(for image: CGImage) -> CGColorSpace? {
        image.colorSpace.flatMap { $0.model == .rgb ? $0 : nil } ?? CGColorSpace(name: CGColorSpace.sRGB)
    }

    /// A BGRA, premultiplied surface holding `image` upright (row 0 = top row),
    /// rendered in the image's own colour space when that is RGB (sRGB otherwise)
    /// and tagged with it.
    static func make(from image: CGImage) -> IOSurface? {
        let width = image.width
        let height = image.height
        guard let colorSpace = colorSpace(for: image),
              let surface = blank(width: width, height: height)
        else { return nil }
        // Core Image puts the image's (0,0) at the surface's lower-left corner,
        // which is the last row in memory, so the surface reads top-down.
        context.render(
            CIImage(cgImage: image),
            to: surface,
            bounds: CGRect(x: 0, y: 0, width: width, height: height),
            colorSpace: colorSpace
        )
        tag(surface, with: colorSpace)
        return surface
    }
}
```

```swift
/// Reads `RenderedSticker.contents`, whichever kind it is.
enum RenderedPixels {
    static func isSurface(_ contents: Any) -> Bool {
        CFGetTypeID(contents as AnyObject) == IOSurfaceGetTypeID()
    }

    static func isImage(_ contents: Any) -> Bool {
        CFGetTypeID(contents as AnyObject) == CGImage.typeID
    }

    static func size(_ contents: Any) -> CGSize? {
        if isSurface(contents), let surface = contents as? IOSurface {
            return CGSize(width: surface.width, height: surface.height)
        }
        if isImage(contents) {
            let image = contents as! CGImage
            return CGSize(width: image.width, height: image.height)
        }
        return nil
    }

    /// The colour space the pixels are in: a CGImage's own, an IOSurface's tag.
    static func colorSpace(_ contents: Any) -> CGColorSpace? {
        if isSurface(contents), let surface = contents as? IOSurface,
           let tag = IOSurfaceCopyValue(surface, kIOSurfaceColorSpace) {
            return CGColorSpace(propertyListPlist: tag)
        }
        if isImage(contents) { return (contents as! CGImage).colorSpace }
        return nil
    }

    /// Premultiplied RGBA bytes, rows top first: an IOSurface's raw BGRA bytes
    /// reordered, a CGImage drawn into sRGB.
    static func rgbaRows(_ contents: Any) -> (width: Int, height: Int, bytes: [UInt8])? {
        if isSurface(contents), let surface = contents as? IOSurface {
            _ = surface.lock(options: .readOnly, seed: nil)
            defer { _ = surface.unlock(options: .readOnly, seed: nil) }
            let base = surface.baseAddress.assumingMemoryBound(to: UInt8.self)
            var bytes = [UInt8](repeating: 0, count: surface.width * surface.height * 4)
            for y in 0..<surface.height {
                for x in 0..<surface.width {
                    let source = base + y * surface.bytesPerRow + x * 4
                    let target = (y * surface.width + x) * 4
                    bytes[target] = source[2]
                    bytes[target + 1] = source[1]
                    bytes[target + 2] = source[0]
                    bytes[target + 3] = source[3]
                }
            }
            return (surface.width, surface.height, bytes)
        }
        if isImage(contents) {
            let image = contents as! CGImage
            let context = CGContext(data: nil, width: image.width, height: image.height, bitsPerComponent: 8,
                                    bytesPerRow: image.width * 4, space: CGColorSpace(name: CGColorSpace.sRGB)!,
                                    bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!
            context.setBlendMode(.copy)
            context.draw(image, in: CGRect(x: 0, y: 0, width: image.width, height: image.height))
            let data = context.data!.assumingMemoryBound(to: UInt8.self)
            return (image.width, image.height, Array(UnsafeBufferPointer(start: data, count: image.width * image.height * 4)))
        }
        return nil
    }

    /// RGBA at (`x`, `y`), y = 0 being the top row.
    static func rgba(_ contents: Any, x: Int, y: Int) -> [UInt8] {
        guard let rows = rgbaRows(contents) else { return [] }
        let offset = (y * rows.width + x) * 4
        return Array(rows.bytes[offset..<offset + 4])
    }

    /// Every pixel's alpha.
    static func alphas(_ contents: Any) -> [UInt8] {
        guard let rows = rgbaRows(contents) else { return [] }
        return stride(from: 3, to: rows.bytes.count, by: 4).map { rows.bytes[$0] }
    }

    /// Rec. 709 luma of the premultiplied colour at (`x`, `y`).
    static func luma(_ contents: Any, x: Int, y: Int) -> Double {
        let p = rgba(contents, x: x, y: y)
        guard p.count == 4 else { return 0 }
        return 0.2126 * Double(p[0]) + 0.7152 * Double(p[1]) + 0.0722 * Double(p[2])
    }
}

/// Renders a Core Image graph into premultiplied sRGB RGBA bytes, rows top first.
enum CIRender {
    private static let context = CIContext(options: [.cacheIntermediates: false])

    static func rgba(_ image: CIImage, width: Int, height: Int) -> [UInt8] {
        var bytes = [UInt8](repeating: 0, count: width * height * 4)
        context.render(image, toBitmap: &bytes, rowBytes: width * 4,
                       bounds: CGRect(x: 0, y: 0, width: width, height: height),
                       format: .RGBA8, colorSpace: CGColorSpace(name: CGColorSpace.sRGB))
        return bytes
    }

    /// The pixel at (`x`, `y`) of `bytes`, y = 0 being the top row.
    static func pixel(_ bytes: [UInt8], width: Int, x: Int, y: Int) -> [UInt8] {
        let offset = (y * width + x) * 4
        return Array(bytes[offset..<offset + 4])
    }
}
```

```swift
import CoreImage
import CoreImage.CIFilterBuiltins
import Foundation

/// The Core Image recipes behind Outline, Shadow and None, and the pieces
/// Puffy shares with Outline (spec section 8). Everything works in bitmap
/// pixels with Core Image's y-up coordinates on premultiplied images; nothing
/// here renders, so `StyleRenderer` decides which context runs the graph.
/// Filters are created per call: `CIFilter` isn't thread-safe.
enum StyleRecipes {
    /// None's choke ramp: alpha × clamp((blurred alpha − 0.7) / 0.35 + 0.5).
    static let chokeCenter = 0.7
    static let chokeWidth = 0.35
    /// The SDF's maximum distance is the distance asked for plus this.
    static let distanceHeadroom = 4.0

    /// `master` scaled to `size` (high-quality downsampling), flipped
    /// horizontally in its own frame when `flipped`, then rotated
    /// counter-clockwise by `rotation` radians, centred on `canvas` and cropped
    /// to it. Outside the master everything stays transparent.
    static func placed(_ master: CIImage, size: CGSize, flipped: Bool, rotation: Double, canvas: CGRect) -> CIImage {
        let extent = master.extent
        guard extent.width > 0, extent.height > 0, size.width > 0, size.height > 0 else { return .empty() }
        // Read bottom-up: centre the master on the origin, scale, flip, rotate, move to the canvas centre.
        var transform = CGAffineTransform(translationX: canvas.midX, y: canvas.midY)
        transform = transform.rotated(by: CGFloat(rotation))
        if flipped { transform = transform.scaledBy(x: -1, y: 1) }
        transform = transform.scaledBy(x: size.width / extent.width, y: size.height / extent.height)
        transform = transform.translatedBy(x: -extent.midX, y: -extent.midY)
        return master.transformed(by: transform, highQualityDownsample: true).cropped(to: canvas)
    }

    /// Premultiplied white with `image`'s alpha, so red equals coverage: the
    /// mask the signed-distance filter reads (never the coloured cutout).
    static func silhouette(of image: CIImage) -> CIImage {
        let matrix = CIFilter.colorMatrix()
        matrix.inputImage = image
        matrix.rVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.gVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.bVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.aVector = CIVector(x: 0, y: 0, z: 0, w: 1)
        matrix.biasVector = CIVector(x: 1, y: 1, z: 1, w: 0)
        return matrix.outputImage ?? .empty()
    }

    /// Everything within `radius` px of `mask`'s opaque area, as premultiplied
    /// white with alpha = clamp(r + 0.5 − d), d from
    /// `CIFilter.signedDistanceGradientFromRedMask()` with D = r + 4 (spec
    /// section 8). Cropped to `canvas` (the distance field itself is infinite).
    static func grown(_ mask: CIImage, by radius: Double, canvas: CGRect) -> CIImage {
        let maxDistance = max(radius, 0) + distanceHeadroom
        let field = CIFilter.signedDistanceGradientFromRedMask()
        field.inputImage = mask
        field.maximumDistance = Float(maxDistance)
        return coverage(field.outputImage, slope: -maxDistance, offset: max(radius, 0) + 0.5, canvas: canvas)
    }

    /// `mask`'s opaque area shrunk by `distance` px: alpha = clamp(0.5 − s − d).
    static func shrunk(_ mask: CIImage, by distance: Double, canvas: CGRect) -> CIImage {
        let maxDistance = max(distance, 0) + distanceHeadroom
        let field = CIFilter.signedDistanceGradientFromRedMask()
        field.inputImage = mask
        field.maximumDistance = Float(maxDistance)
        return coverage(field.outputImage, slope: -maxDistance, offset: 0.5 - max(distance, 0), canvas: canvas)
    }

    /// White with alpha = clamp(slope × red + offset) for an opaque distance
    /// field whose red channel is the signed distance / D.
    private static func coverage(_ field: CIImage?, slope: Double, offset: Double, canvas: CGRect) -> CIImage {
        guard let field else { return .empty() }
        let matrix = CIFilter.colorMatrix()
        matrix.inputImage = field
        matrix.rVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.gVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.bVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.aVector = CIVector(x: CGFloat(slope), y: 0, z: 0, w: 0)
        matrix.biasVector = CIVector(x: 1, y: 1, z: 1, w: CGFloat(offset))
        return clamped(matrix.outputImage).cropped(to: canvas)
    }

    /// Every component clamped to 0–1.
    static func clamped(_ image: CIImage?) -> CIImage {
        guard let image else { return .empty() }
        let clamp = CIFilter.colorClamp()
        clamp.inputImage = image
        clamp.minComponents = CIVector(x: 0, y: 0, z: 0, w: 0)
        clamp.maxComponents = CIVector(x: 1, y: 1, z: 1, w: 1)
        return clamp.outputImage ?? .empty()
    }

    /// The white die-cut rim around `subject` (alpha = coverage, the subject's
    /// own area included). With `closing` s > 0 the mask grows by r + s and
    /// shrinks back by s, which bridges notches narrower than about 2s for a
    /// smoother line; the intermediate keeps s + 2 px beyond the canvas, so the
    /// shrink never starts from the canvas edge.
    static func rim(around subject: CIImage, radius: Double, closing: Double, canvas: CGRect) -> CIImage {
        let mask = silhouette(of: subject)
        guard closing > 0 else { return grown(mask, by: radius, canvas: canvas) }
        let room = canvas.insetBy(dx: -CGFloat(closing + 2), dy: -CGFloat(closing + 2))
        return shrunk(grown(mask, by: radius + closing, canvas: room), by: closing, canvas: canvas)
    }

    /// Outline: the cutout over its white rim (the layer adds the drop shadow).
    static func outline(subject: CIImage, rim: CIImage, canvas: CGRect) -> CIImage {
        subject.composited(over: rim).cropped(to: canvas)
    }

    /// None's (and Shadow's) edge choke: the alpha is multiplied by
    /// clamp((a − 0.7) / 0.35 + 0.5) of the alpha blurred with σ = `sigma` px,
    /// which removes the light halo a 512 px Vision mask leaves around a cutout.
    static func choked(_ image: CIImage, sigma: Double, canvas: CGRect) -> CIImage {
        let blurred = sigma > 0 ? image.applyingGaussianBlur(sigma: sigma) : image
        let ramp = CIFilter.colorMatrix()
        ramp.inputImage = blurred
        ramp.rVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        ramp.gVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        ramp.bVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        ramp.aVector = CIVector(x: 0, y: 0, z: 0, w: CGFloat(1 / chokeWidth))
        ramp.biasVector = CIVector(x: 0, y: 0, z: 0, w: CGFloat(0.5 - chokeCenter / chokeWidth))
        let blend = CIFilter.blendWithAlphaMask()
        blend.inputImage = image
        blend.backgroundImage = CIImage.empty()
        blend.maskImage = clamped(ramp.outputImage)
        return (blend.outputImage ?? .empty()).cropped(to: canvas)
    }
}
```

```swift
import CoreImage
import CoreImage.CIFilterBuiltins
import Foundation
import os

/// Puffy (spec section 8): the cutout over its white rim, shaded as an
/// inflated dome lit from the top-left in screen space.
///
/// The dome's height is the mean of three Gaussian blurs of the rim mask
/// (σ = R/3, 2R/3, R), averaged inside a Metal Core Image kernel that also
/// computes the normals (central differences, ±1.5 px) and applies Lambert +
/// Blinn-Phong light. The kernel source is a Swift string compiled at runtime
/// with `CIKernel.kernels(withMetalString:)`: a `.metal` file in the target
/// would need the separately downloaded Metal Toolchain. It is compiled once,
/// off the main thread (`StyleRenderer.prewarm()` reads `compiled` on the
/// render queue). If compiling throws, Puffy falls back to built-in filters
/// (Sobel gradients, a Lambert colour matrix and a screen-blended specular),
/// and if even those give no image, to the plain rim (Outline's look).
enum PuffyKernel {
    enum Path: String, Equatable {
        case kernel
        case builtIn
        case rimOnly
    }

    struct Compiled {
        let kernel: CIKernel?
        let error: Error?
        let seconds: TimeInterval
        let onMainThread: Bool
    }

    static let functionName = "puffyShade"
    static let ambient = 0.35
    static let diffuse = 0.65
    static let shininess = 40.0
    static let specular = 0.55
    /// Light from the top-left: 135° in Core Image's y-up space.
    static let lightAngle = 135.0 * Double.pi / 180
    static let lightPlanar = 0.55
    static let lightZ = 0.63
    /// Central-difference step for the normals, in pixels.
    static let normalStep = 1.5

    static var light: (x: Double, y: Double, z: Double) {
        (lightPlanar * cos(lightAngle), lightPlanar * sin(lightAngle), lightZ)
    }

    static let source = """
    #include <metal_stdlib>
    using namespace metal;
    #include <CoreImage/CoreImage.h>

    namespace stickermine {
        // The dome's height at p: the mean of the three blurred rim masks.
        inline float domeHeight(coreimage::sampler h1, coreimage::sampler h2, coreimage::sampler h3, float2 p) {
            return (h1.sample(h1.transform(p)).a + h2.sample(h2.transform(p)).a + h3.sample(h3.transform(p)).a) / 3.0;
        }
    }

    extern "C" {
    namespace coreimage {

    [[stitchable]] float4 puffyShade(sampler base, sampler h1, sampler h2, sampler h3,
                                     float3 light, float heightPx, float step, float ambient, float diffuse,
                                     float shininess, float specular, destination dest) {
        float2 p = dest.coord();
        float4 c = base.sample(base.transform(p));
        if (c.a <= 0.0) {
            return float4(0.0);
        }
        float dx = stickermine::domeHeight(h1, h2, h3, p + float2(step, 0.0))
                 - stickermine::domeHeight(h1, h2, h3, p - float2(step, 0.0));
        float dy = stickermine::domeHeight(h1, h2, h3, p + float2(0.0, step))
                 - stickermine::domeHeight(h1, h2, h3, p - float2(0.0, step));
        float slope = heightPx / (2.0 * step);
        float3 n = normalize(float3(-dx * slope, -dy * slope, 1.0));
        float lambert = max(dot(n, light), 0.0);
        float shade = (ambient + diffuse * lambert) / (ambient + diffuse * light.z);
        float3 halfway = normalize(light + float3(0.0, 0.0, 1.0));
        float highlight = specular * pow(max(dot(n, halfway), 0.0), shininess);
        float3 rgb = c.rgb * shade + highlight * c.a;
        return float4(min(rgb, float3(c.a)), c.a);
    }

    }
    }
    """

    private static let log = Logger(subsystem: "com.ethan.stickermine", category: "render")

    /// The kernel, compiled the first time anything reads this (thread-safe,
    /// exactly once per process).
    static let compiled: Compiled = compile(source)

    /// Compiles `source` and logs how long it took or why it failed.
    static func compile(_ source: String) -> Compiled {
        let start = Date()
        let onMain = Thread.isMainThread
        do {
            let kernels = try CIKernel.kernels(withMetalString: source)
            guard let kernel = kernels.first(where: { $0.name == functionName }) else {
                throw CocoaError(.featureUnsupported)
            }
            let seconds = Date().timeIntervalSince(start)
            log.notice("Puffy kernel compiled in \(Int(seconds * 1000)) ms")
            return Compiled(kernel: kernel, error: nil, seconds: seconds, onMainThread: onMain)
        } catch {
            log.error("Puffy kernel failed to compile, using built-in filters: \(String(describing: error), privacy: .public)")
            return Compiled(kernel: nil, error: error, seconds: Date().timeIntervalSince(start), onMainThread: onMain)
        }
    }

    /// The three height fields: the rim mask blurred at σ = R/3, 2R/3 and R.
    static func heightFields(rim: CIImage, domeRadius: Double) -> [CIImage] {
        [domeRadius / 3, 2 * domeRadius / 3, domeRadius].map { rim.applyingGaussianBlur(sigma: $0) }
    }

    /// Shades `base` (the cutout over its rim) with a dome of radius
    /// `domeRadius` px built from `rim`, trying the kernel first (when
    /// `useKernel` and it compiled), then the built-in filters, then nothing.
    static func shade(base: CIImage, rim: CIImage, domeRadius: Double, canvas: CGRect,
                      useKernel: Bool) -> (image: CIImage, path: Path) {
        if useKernel, let kernel = compiled.kernel,
           let image = shadeWithKernel(kernel, base: base, rim: rim, domeRadius: domeRadius, canvas: canvas) {
            return (image, .kernel)
        }
        if let image = shadeWithBuiltInFilters(base: base, rim: rim, domeRadius: domeRadius, canvas: canvas) {
            return (image, .builtIn)
        }
        return (base.cropped(to: canvas), .rimOnly)
    }

    static func shadeWithKernel(_ kernel: CIKernel, base: CIImage, rim: CIImage, domeRadius: Double,
                                canvas: CGRect) -> CIImage? {
        let heights = heightFields(rim: rim, domeRadius: domeRadius)
        let margin = CGFloat(normalStep + 2)
        let light = light
        return kernel.apply(
            extent: canvas,
            roiCallback: { index, rect in index == 0 ? rect : rect.insetBy(dx: -margin, dy: -margin) },
            arguments: [
                base, heights[0], heights[1], heights[2],
                CIVector(x: CGFloat(light.x), y: CGFloat(light.y), z: CGFloat(light.z)),
                StyleParameters.domeHeightPerRadius * domeRadius, normalStep,
                ambient, diffuse, shininess, specular,
            ])
    }

    /// The fallback, built-in filters only. One blur (σ = 2R/3) is the height,
    /// so nothing is summed. `CISobelGradients` gives 8 × the slope per pixel
    /// (red: x, green: y upwards), lightly blurred against the bands a large
    /// blur's interpolation leaves. A colour matrix turns the gradients into a
    /// linearised Lambert factor that multiplies the colours, and into u, the
    /// slope towards the light. The specular is a tent in u that peaks where
    /// the surface faces the halfway vector and is gone at u = 0 and u = 1,
    /// squared and screened on: less glossy than the kernel, never a flat wash.
    static func shadeWithBuiltInFilters(base: CIImage, rim: CIImage, domeRadius: Double, canvas: CGRect) -> CIImage? {
        let height = rim.applyingGaussianBlur(sigma: 2 * domeRadius / 3)
        let sobel = CIFilter.sobelGradients()
        sobel.inputImage = height
        guard let raw = sobel.outputImage else { return nil }
        let gradients = raw.clampedToExtent().applyingGaussianBlur(sigma: 1.5).cropped(to: canvas)
        let slope = StyleParameters.domeHeightPerRadius * domeRadius / 8
        let light = light
        let flat = ambient + diffuse * light.z

        // Lambert: (ambient + diffuse × N·L) / (ambient + diffuse × Lz), with
        // N·L ≈ Lz − Lx·sx − Ly·sy for the slopes sx, sy.
        let lx = -diffuse * light.x * slope / flat
        let ly = -diffuse * light.y * slope / flat
        let factor = gray(gradients, x: lx, y: ly, bias: 1, min: 0, max: 2)
        let opaqueBase = base.unpremultiplyingAlpha().settingAlphaOne(in: canvas)
        let lit = CIFilter.multiplyCompositing()
        lit.inputImage = factor
        lit.backgroundImage = opaqueBase

        // u = −slope × (d · gradient) for the light's planar direction d; the
        // halfway vector's tilt puts the tent's peak at u0 = |Hxy| / Hz.
        let ux = -slope * cos(lightAngle)
        let uy = -slope * sin(lightAngle)
        let hz = light.z + 1
        let peak = (light.x * light.x + light.y * light.y).squareRoot() / hz
        let rising = gray(gradients, x: ux / peak, y: uy / peak, bias: 0, min: 0, max: 1)
        let falling = gray(gradients, x: -ux / (1 - peak), y: -uy / (1 - peak), bias: 1 / (1 - peak), min: 0, max: 1)
        let tent = CIFilter.minimumCompositing()
        tent.inputImage = rising
        tent.backgroundImage = falling
        let sharpen = CIFilter.gammaAdjust()
        sharpen.inputImage = tent.outputImage
        sharpen.power = 2
        let amount = CIFilter.colorMatrix()
        amount.inputImage = sharpen.outputImage
        amount.rVector = CIVector(x: CGFloat(specular), y: 0, z: 0, w: 0)
        amount.gVector = CIVector(x: 0, y: CGFloat(specular), z: 0, w: 0)
        amount.bVector = CIVector(x: 0, y: 0, z: CGFloat(specular), w: 0)
        amount.aVector = CIVector(x: 0, y: 0, z: 0, w: 1)

        let screen = CIFilter.screenBlendMode()
        screen.inputImage = amount.outputImage
        screen.backgroundImage = lit.outputImage
        let masked = CIFilter.blendWithAlphaMask()
        masked.inputImage = StyleRecipes.clamped(screen.outputImage)
        masked.backgroundImage = CIImage.empty()
        masked.maskImage = base
        return masked.outputImage?.cropped(to: canvas)
    }

    /// Opaque gray = clamp(x × red + y × green + bias) of an opaque image.
    private static func gray(_ image: CIImage, x: Double, y: Double, bias: Double, min: Double, max: Double) -> CIImage {
        let matrix = CIFilter.colorMatrix()
        matrix.inputImage = image
        let row = CIVector(x: CGFloat(x), y: CGFloat(y), z: 0, w: 0)
        matrix.rVector = row
        matrix.gVector = row
        matrix.bVector = row
        matrix.aVector = CIVector(x: 0, y: 0, z: 0, w: 0)
        matrix.biasVector = CIVector(x: CGFloat(bias), y: CGFloat(bias), z: CGFloat(bias), w: 1)
        let clamp = CIFilter.colorClamp()
        clamp.inputImage = matrix.outputImage
        clamp.minComponents = CIVector(x: CGFloat(min), y: CGFloat(min), z: CGFloat(min), w: 1)
        clamp.maxComponents = CIVector(x: CGFloat(max), y: CGFloat(max), z: CGFloat(max), w: 1)
        return clamp.outputImage ?? CIImage(color: CIColor(red: CGFloat(bias), green: CGFloat(bias), blue: CGFloat(bias)))
    }

    /// The longest side of the copy `inscribedRadius(of:context:)` measures.
    static let inscribedProxyLongSide = 1024.0

    /// The radius of the largest circle inside `master`'s opaque area, in the
    /// master's pixels. Measured once per sticker on a copy at most 1024 px
    /// long (the distance field's maximum distance is 1000), with
    /// `CIAreaMinimum` and a 1×1 float readback; `StyleRenderer` caches it.
    static func inscribedRadius(of master: CGImage, context: CIContext) -> Double {
        let longSide = Double(max(master.width, master.height))
        guard longSide > 0 else { return 0 }
        let scale = min(1, inscribedProxyLongSide / longSide)
        let proxy = CIImage(cgImage: master).transformed(
            by: CGAffineTransform(scaleX: CGFloat(scale), y: CGFloat(scale)), highQualityDownsample: true)
        let field = CIFilter.signedDistanceGradientFromRedMask()
        field.inputImage = StyleRecipes.silhouette(of: proxy)
        field.maximumDistance = 1000
        let minimum = CIFilter.areaMinimum()
        minimum.inputImage = field.outputImage
        minimum.extent = proxy.extent
        guard let pixel = minimum.outputImage else { return 0 }
        var rgba = [Float](repeating: 0, count: 4)
        context.render(pixel, toBitmap: &rgba, rowBytes: 16,
                       bounds: CGRect(origin: pixel.extent.origin, size: CGSize(width: 1, height: 1)),
                       format: .RGBAf, colorSpace: nil)
        // The field measures between pixel centres, half a pixel past the edge.
        let inside = Double(-rgba[0]) * 1000 - 0.5
        return max(0, inside) / scale
    }
}
```

```swift
final class Flag: @unchecked Sendable {
    private let lock = NSLock()
    private var value = false

    func set() {
        lock.lock()
        value = true
        lock.unlock()
    }

    var isSet: Bool {
        lock.lock()
        defer { lock.unlock() }
        return value
    }
```

```swift
import CoreGraphics
import CoreImage
import Foundation
import IOSurface
import Metal
import os

/// Everything a sticker's bitmap depends on. Two equal requests give the same bitmap.
struct RenderRequest: Equatable {
    let sticker: UUID
    let style: StickerStyle
    let flipped: Bool
    /// Radians, counter-clockwise on screen.
    let rotation: Double
    /// The unrotated on-screen size in points (natural size × pose scale).
    let pointSize: CGSize
    let backingScale: CGFloat
}

extension RenderRequest {
    /// The style parameters for the sticker's on-screen size (unrotated long
    /// side in points × backing scale): what the layer shadow and the window's
    /// margin use. The bitmap's own rim and dome use the parameters of its
    /// possibly capped pixel size instead.
    func onScreenParameters(sourceLongSide: Double) -> StyleParameters {
        StyleParameters.forStickerPixels(
            longSide: Double(max(pointSize.width, pointSize.height) * backingScale),
            sourceLongSide: sourceLongSide)
    }
}

struct RenderedSticker {
    /// An IOSurface or a CGImage (`StyleRenderer.Options.contents`), set as `CALayer.contents`.
    let contents: Any
    /// The bitmap's size in pixels (long side at most `StyleRenderer.maxPixelLongSide`).
    let pixelSize: CGSize
    /// The rotated bounding box of the sticker in points, without shadow margin.
    let pointBounds: CGSize
    let alphaMask: AlphaMask
    /// The backing scale the bitmap was rendered for; the layer shadow turns
    /// its pixel parameters into points with it.
    let backingScale: CGFloat
}

/// A coarse copy of the bitmap's alpha (long side at most 512): a cell is the
/// largest alpha among the pixels it covers, so any visible pixel marks it.
struct AlphaMask {
    let width: Int
    let height: Int
    /// Row-major, row 0 at the top.
    let bytes: [UInt8]

    /// `p` in 0–1 with the origin at the top-left of the bitmap.
    func isOpaque(atUnit p: CGPoint) -> Bool {
        guard width > 0, height > 0, bytes.count == width * height,
              p.x >= 0, p.x <= 1, p.y >= 0, p.y <= 1
        else { return false }
        let x = min(width - 1, Int(p.x * CGFloat(width)))
        let y = min(height - 1, Int(p.y * CGFloat(height)))
        return bytes[y * width + x] > 0
    }
}

/// Renders a sticker's styled bitmap (spec sections 8 and 9).
///
/// One serial queue does every render off the main thread, with one shared
/// Metal-backed `CIContext` (half-float working format) for Outline, Shadow and
/// None and one RGBAf context for Puffy; caches are cleared after each bake.
/// The bitmap is the rotated box of the sticker (plus its rim for Outline and
/// Puffy, so the subject keeps its size in every style) at the on-screen pixel
/// size, capped at 2048 px on the long side (the layer scales it up beyond
/// that), with flip and rotation baked in, so the Puffy light stays top-left
/// on screen. Alpha
/// below about 0.02 is cleared so faint fringes never catch clicks; the drop
/// shadow is never baked (`StickerView` draws it as a layer shadow).
///
/// Thread-safe: its mutable state is behind `lock`, `CIContext` is thread-safe,
/// and every `CIFilter` is created per render.
final class StyleRenderer: @unchecked Sendable {
    enum RenderError: Error, Equatable {
        case missingMaster
        case emptySize
        case contextFailed
    }

    /// What `RenderedSticker.contents` holds.
    enum Contents: Equatable {
        case surface
        case image
    }

    struct Options: Equatable {
        var contents: Contents
        /// Outline and Puffy close the rim (grow by r + s, shrink by s).
        var closesRim: Bool
        /// False forces Puffy's built-in-filter fallback (tests, the gallery).
        var usesPuffyKernel: Bool

        static let standard = Options(contents: StyleRenderer.defaultContents, closesRim: true, usesPuffyKernel: true)
    }

    /// From design/spike-results.md, Decisions: "Contents type for M3: IOSurface
    /// or CGImage?" IOSurface contents cost about half the memory of a CGImage.
    static let defaultContents: Contents = .surface
    static let maxPixelLongSide: Double = 2048
    static let maxMaskLongSide = 512
    /// Alpha below this (about 0.02 × 255) becomes 0.
    static let alphaFloor: UInt8 = 5

    let options: Options
    private let masterProvider: (UUID) -> CGImage?
    private let queue = DispatchQueue(label: "com.ethan.stickermine.render", qos: .userInitiated)
    private let standardContext: CIContext
    private let puffyContext: CIContext
    private let hasMetal: Bool
    private let log = Logger(subsystem: "com.ethan.stickermine", category: "render")

    private struct Inscribed {
        let width: Int
        let height: Int
        let radius: Double
    }

    private let lock = NSLock()
    private var inscribed: [UUID: Inscribed] = [:]
    private var measurements = 0
    private var puffyPath: PuffyKernel.Path?

    /// `masterProvider` loads a sticker's master image. It is called off the
    /// main thread and must be thread-safe.
    init(masterProvider: @escaping (UUID) -> CGImage?, options: Options = .standard) {
        self.masterProvider = masterProvider
        self.options = options
        let device = MTLCreateSystemDefaultDevice()
        hasMetal = device != nil
        standardContext = Self.makeContext(device: device, workingFormat: nil)
        puffyContext = Self.makeContext(device: device, workingFormat: .RGBAf)
    }

    private static func makeContext(device: MTLDevice?, workingFormat: CIFormat?) -> CIContext {
        var contextOptions: [CIContextOption: Any] = [.cacheIntermediates: false]
        if let workingFormat { contextOptions[.workingFormat] = workingFormat }
        if let device { return CIContext(mtlDevice: device, options: contextOptions) }
        return CIContext(options: contextOptions)
    }

    func render(_ request: RenderRequest) async throws -> RenderedSticker {
        try await withCheckedThrowingContinuation { continuation in
            queue.async {
                continuation.resume(with: Result { try self.renderNow(request) })
            }
        }
    }

    /// Compiles the Puffy kernel on the render queue (off the main thread) and
    /// returns at once; a render queued afterwards waits for it.
    func prewarm() {
        queue.async { [log] in
            let compiled = PuffyKernel.compiled
            if compiled.kernel != nil {
                log.notice("Puffy kernel ready (\(Int(compiled.seconds * 1000)) ms)")
            }
        }
    }

    /// How many inscribed radii were measured (each sticker once), for tests.
    var inscribedMeasurementCount: Int {
        lock.lock()
        defer { lock.unlock() }
        return measurements
    }

    /// Which Puffy recipe drew the latest Puffy bitmap.
    var lastPuffyPath: PuffyKernel.Path? {
        lock.lock()
        defer { lock.unlock() }
        return puffyPath
    }

    /// Forgets what was measured for `sticker`; call it if a sticker's master
    /// ever changes under the same ID.
    func invalidateCache(for sticker: UUID) {
        lock.lock()
        inscribed[sticker] = nil
        lock.unlock()
    }

    /// Renders on the calling thread. The app only reaches it through `render`
    /// (the render queue); the gallery and tests call it from background tasks.
    func renderNow(_ request: RenderRequest) throws -> RenderedSticker {
        guard let master = masterProvider(request.sticker) else { throw RenderError.missingMaster }
        guard request.pointSize.width > 0, request.pointSize.height > 0, request.backingScale > 0,
              master.width > 0, master.height > 0
        else { throw RenderError.emptySize }
        let canvas = Self.canvas(for: request)
        let bounds = CGRect(x: 0, y: 0, width: canvas.width, height: canvas.height)
        guard let colorSpace = SurfaceContents.colorSpace(for: master) else { throw RenderError.contextFailed }
        let (image, context) = styled(master: master, request: request, drawSize: canvas.drawSize, bounds: bounds)
        defer { context.clearCaches() }
        if options.contents == .surface,
           let surface = renderSurface(image, context: context, bounds: bounds, colorSpace: colorSpace) {
            return RenderedSticker(contents: surface.surface, pixelSize: bounds.size, pointBounds: canvas.pointBounds,
                                   alphaMask: surface.mask, backingScale: request.backingScale)
        }
        let bitmap = try renderImage(image, context: context, bounds: bounds, colorSpace: colorSpace)
        return RenderedSticker(contents: bitmap.image, pixelSize: bounds.size, pointBounds: canvas.pointBounds,
                               alphaMask: bitmap.mask, backingScale: request.backingScale)
    }

    /// The canvas for a request: the rotated bounding box in pixels of the
    /// sticker plus its rim (Outline and Puffy reach `rimReach` beyond the
    /// subject on every side), capped at `maxPixelLongSide`; the size the
    /// unrotated master is drawn at; and the rotated box in points.
    static func canvas(for request: RenderRequest) -> (width: Int, height: Int, drawSize: CGSize, pointBounds: CGSize) {
        let reach = CGFloat(request.onScreenParameters(sourceLongSide: 0).rimReach(for: request.style))
        let pixelSize = CGSize(width: request.pointSize.width * request.backingScale,
                               height: request.pointSize.height * request.backingScale)
        let outer = CGSize(width: pixelSize.width + 2 * reach, height: pixelSize.height + 2 * reach)
        let box = StickerGeometry.boundingSize(of: outer, rotation: request.rotation)
        let longSide = max(box.width, box.height)
        let cap = longSide > maxPixelLongSide ? maxPixelLongSide / longSide : 1
        // The tiny allowance keeps 100.000000001 from becoming 101 after rotation.
        let width = max(1, Int((box.width * cap - 0.001).rounded(.up)))
        let height = max(1, Int((box.height * cap - 0.001).rounded(.up)))
        let drawSize = CGSize(width: pixelSize.width * cap, height: pixelSize.height * cap)
        let reachPoints = reach / request.backingScale
        let outerPoints = CGSize(width: request.pointSize.width + 2 * reachPoints,
                                 height: request.pointSize.height + 2 * reachPoints)
        return (width, height, drawSize, StickerGeometry.boundingSize(of: outerPoints, rotation: request.rotation))
    }

    /// The styled image for `request` on a canvas of `bounds`, and the context
    /// to render it with. `drawSize` is the unrotated master in bitmap pixels;
    /// a rim is drawn around it, inside the canvas's room for it.
    private func styled(master: CGImage, request: RenderRequest, drawSize: CGSize,
                        bounds: CGRect) -> (CIImage, CIContext) {
        let source = CIImage(cgImage: master)
        let longSide = Double(max(drawSize.width, drawSize.height))
        let parameters = StyleParameters.forStickerPixels(
            longSide: longSide, sourceLongSide: Double(max(master.width, master.height)))
        // Bitmap pixels per master pixel.
        let pixelRatio = Double(drawSize.width) / Double(master.width)
        let subject = StyleRecipes.placed(source, size: drawSize, flipped: request.flipped,
                                          rotation: request.rotation, canvas: bounds)
        let closing = options.closesRim ? parameters.closing : 0
        switch request.style {
        case .none, .shadow:
            return (StyleRecipes.choked(subject, sigma: parameters.chokeSigma * pixelRatio, canvas: bounds),
                    standardContext)
        case .outline:
            let rim = StyleRecipes.rim(around: subject, radius: parameters.rimRadius, closing: closing, canvas: bounds)
            return (StyleRecipes.outline(subject: subject, rim: rim, canvas: bounds), standardContext)
        case .puffy:
            let rim = StyleRecipes.rim(around: subject, radius: parameters.rimRadius, closing: closing, canvas: bounds)
            let base = StyleRecipes.outline(subject: subject, rim: rim, canvas: bounds)
            let inscribedRadius = inscribedRadius(for: request.sticker, master: master) * pixelRatio
                + parameters.rimRadius
            let domeRadius = StyleParameters.domeRadius(inscribedRadius: inscribedRadius, longSide: longSide)
            let shaded = PuffyKernel.shade(base: base, rim: rim, domeRadius: domeRadius, canvas: bounds,
                                           useKernel: options.usesPuffyKernel && hasMetal)
            lock.lock()
            puffyPath = shaded.path
            lock.unlock()
            return (shaded.image, puffyContext)
        }
    }

    /// The master's inscribed radius in master pixels, measured once per sticker.
    private func inscribedRadius(for sticker: UUID, master: CGImage) -> Double {
        lock.lock()
        if let cached = inscribed[sticker], cached.width == master.width, cached.height == master.height {
            lock.unlock()
            return cached.radius
        }
        lock.unlock()
        let radius = PuffyKernel.inscribedRadius(of: master, context: puffyContext)
        lock.lock()
        inscribed[sticker] = Inscribed(width: master.width, height: master.height, radius: radius)
        measurements += 1
        lock.unlock()
        return radius
    }

    /// Renders into a new IOSurface tagged with `colorSpace`, clearing faint
    /// alpha in place. nil when the surface can't be made.
    private func renderSurface(_ image: CIImage, context: CIContext, bounds: CGRect,
                               colorSpace: CGColorSpace) -> (surface: IOSurface, mask: AlphaMask)? {
        let width = Int(bounds.width)
        let height = Int(bounds.height)
        guard let surface = SurfaceContents.blank(width: width, height: height) else { return nil }
        // Core Image's y-up origin lands on the last row, so memory row 0 is the top.
        context.render(image, to: surface, bounds: bounds, colorSpace: colorSpace)
        _ = surface.lock(options: [], seed: nil)
        let mask = Self.clampAlphaAndBuildMask(
            pixels: surface.baseAddress.assumingMemoryBound(to: UInt8.self),
            width: width, height: height, rowBytes: surface.bytesPerRow)
        _ = surface.unlock(options: [], seed: nil)
        SurfaceContents.tag(surface, with: colorSpace)
        return (surface, mask)
    }

    /// Renders into an RGBA8 premultiplied bitmap in `colorSpace` and makes a CGImage.
    private func renderImage(_ image: CIImage, context: CIContext, bounds: CGRect,
                             colorSpace: CGColorSpace) throws -> (image: CGImage, mask: AlphaMask) {
        let width = Int(bounds.width)
        let height = Int(bounds.height)
        guard let bitmap = CGContext(
                  data: nil, width: width, height: height, bitsPerComponent: 8,
                  bytesPerRow: width * 4, space: colorSpace,
                  bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue),
              let data = bitmap.data
        else { throw RenderError.contextFailed }
        context.render(image, toBitmap: data, rowBytes: width * 4, bounds: bounds, format: .RGBA8,
                       colorSpace: colorSpace)
        let mask = Self.clampAlphaAndBuildMask(
            pixels: data.bindMemory(to: UInt8.self, capacity: width * height * 4),
            width: width, height: height, rowBytes: width * 4)
        guard let cgImage = bitmap.makeImage() else { throw RenderError.contextFailed }
        return (cgImage, mask)
    }

    /// One pass over premultiplied 4-byte pixels (RGBA or BGRA: alpha is the
    /// fourth byte) with rows `rowBytes` apart, row 0 at the top: clears pixels
    /// whose alpha is below `alphaFloor` and records the largest alpha per mask cell.
    static func clampAlphaAndBuildMask(pixels: UnsafeMutablePointer<UInt8>, width: Int, height: Int,
                                       rowBytes: Int) -> AlphaMask {
        let longSide = max(width, height)
        let factor = longSide > maxMaskLongSide ? Double(maxMaskLongSide) / Double(longSide) : 1
        let maskWidth = max(1, Int((Double(width) * factor).rounded(.up)))
        let maskHeight = max(1, Int((Double(height) * factor).rounded(.up)))
        var bytes = [UInt8](repeating: 0, count: maskWidth * maskHeight)
        bytes.withUnsafeMutableBufferPointer { mask in
            for y in 0..<height {
                let maskRow = min(maskHeight - 1, y * maskHeight / height) * maskWidth
                let row = pixels + y * rowBytes
                for x in 0..<width {
                    let pixel = row + x * 4
                    let alpha = pixel[3]
                    if alpha < alphaFloor {
                        if alpha != 0 { pixel[0] = 0; pixel[1] = 0; pixel[2] = 0; pixel[3] = 0 }
                        continue
                    }
                    let cell = maskRow + min(maskWidth - 1, x * maskWidth / width)
                    if alpha > mask[cell] { mask[cell] = alpha }
                }
            }
        }
        return AlphaMask(width: maskWidth, height: maskHeight, bytes: bytes)
    }

    /// Tightly packed rows (`rowBytes` = width × 4), as M2's baseline used.
    static func clampAlphaAndBuildMask(pixels: UnsafeMutablePointer<UInt8>, width: Int, height: Int) -> AlphaMask {
        clampAlphaAndBuildMask(pixels: pixels, width: width, height: height, rowBytes: width * 4)
    }
}
```

```swift
import AppKit

/// The content view of a StickerPanel: a layer-hosting view whose root layer
/// holds three sublayers we own, back to front:
/// - `hitPadLayer`: alpha 1/255 over the whole padded frame while editing, so the
///   transparent parts of the box (and later the corner knob) can be grabbed;
///   hidden otherwise, so transparent pixels click through.
/// - `contentLayer`: the sticker bitmap (CGImage or IOSurface), centred, with the
///   layer shadow. Gesture transforms go on this layer, never on the root.
/// - `outlineLayer`: the subtle editing outline.
@MainActor
final class StickerView: NSView {
    let contentLayer = CALayer()
    let hitPadLayer = CALayer()
    let outlineLayer = CAShapeLayer()

    /// A double-click on an inactive (not editing) sticker.
    var onDoubleClick: (() -> Void)?
    /// Key presses while the panel is key. Return true when handled.
    var onKeyDown: ((NSEvent) -> Bool)?
    /// Trackpad pinch and rotate, delivered whatever the editing state.
    var onMagnify: ((NSEvent) -> Void)?
    var onRotate: ((NSEvent) -> Void)?
    /// Called right after `performDrag(with:)` returns for a drag started while editing.
    var onDragEnded: (() -> Void)?

    /// re-rendered at the new scale (spec section 11).

    private(set) var contentPointSize: CGSize = .zero
    private(set) var layerShadow: LayerShadow?
    /// The transparent padding the window keeps on every side of the shown
    /// bitmap's box, in points: `StyleParameters.shadowMargin(for:)` over the
    /// backing scale for a rendered sticker, `LayerShadow.margin` for raw

    private(set) var contentScale: CGFloat = 1
    private(set) var contentRotation: CGFloat = 0
    private(set) var isShowingEditingChrome = false

        super.init(frame: frameRect)
        let root = CALayer()
        root.isOpaque = false
        // Assigning the layer before wantsLayer makes this a layer-hosting view:
        // AppKit leaves the layer tree to us.

        root.addSublayer(contentLayer)
        root.addSublayer(outlineLayer)

        fatalError("StickerView is only created in code")
    }

    /// rect plus the shadow margin on every side (zero margin without a shadow).
    static func frameSize(pointSize: CGSize, shadow: LayerShadow?) -> CGSize {
        let margin = shadow?.margin ?? 0
        return CGSize(width: pointSize.width + 2 * margin, height: pointSize.height + 2 * margin)
    }

    /// The axis-aligned bounding box of `size` scaled by `scale` and rotated by
    /// `rotation` radians.
    static func boundingSize(of size: CGSize, scale: CGFloat, rotation: CGFloat) -> CGSize {
        let c = abs(cos(rotation))
        let s = abs(sin(rotation))
        return CGSize(
            width: (size.width * c + size.height * s) * scale,
            height: (size.width * s + size.height * c) * scale
        )
    }

    /// Shows `contents` (a CGImage or an IOSurface, as accepted by
    /// `CALayer.contents`) at `pointSize`, with an optional layer shadow.
    /// `frameMargin` defaults to the shadow's own margin (0 without one);
    /// `show(_:shadow:style:)` passes `StyleParameters.shadowMargin` in points.
    func showContents(_ contents: Any, pointSize: CGSize, shadow: LayerShadow?, frameMargin: CGFloat? = nil) {
        contentPointSize = pointSize
        layerShadow = shadow
        self.frameMargin = frameMargin ?? shadow?.margin ?? 0
        withoutAnimation {
            contentLayer.contents = contents
            if let shadow {
                contentLayer.shadowColor = NSColor.black.cgColor
                contentLayer.shadowOpacity = shadow.opacity
                contentLayer.shadowRadius = shadow.radius
                // Layer-hosting views aren't flipped: negative y points down.
                contentLayer.shadowOffset = CGSize(width: 0, height: -shadow.offset)
            } else {
                contentLayer.shadowOpacity = 0
            }
        }
        layoutStickerLayers()
    }

    /// Shows a rendered sticker at its point bounds with its drop shadow:
    /// `shadow` holds the style parameters for the sticker's on-screen pixel
    /// size (`RenderRequest.onScreenParameters(sourceLongSide:)`), which become
    /// points through the backing scale the bitmap was rendered for. None, or
    /// a nil `shadow`, shows no shadow and needs no margin (spec sections 8–9).
    /// The shadow stays unrasterized: the content is static between gestures.
    func show(_ rendered: RenderedSticker, shadow: StyleParameters?, style: StickerStyle) {
        let layer = Self.layerShadow(for: shadow, style: style, backingScale: rendered.backingScale)
        let margin = layer == nil ? 0 : CGFloat(shadow?.shadowMargin(for: style) ?? 0) / rendered.backingScale
        showContents(rendered.contents, pointSize: rendered.pointBounds, shadow: layer, frameMargin: margin)
    }

    /// The layer shadow for pixel `parameters` at `backingScale`: black at the
    /// parameters' opacity, radius and downward offset in points. nil for None,
    /// without parameters, or when the radius is zero.
    static func layerShadow(for parameters: StyleParameters?, style: StickerStyle,
                            backingScale: CGFloat) -> LayerShadow? {
        guard let parameters, style != .none, backingScale > 0, parameters.shadowRadius > 0 else { return nil }
        return LayerShadow(radius: CGFloat(parameters.shadowRadius) / backingScale,
                           opacity: Float(parameters.shadowOpacity),
                           offset: CGFloat(parameters.shadowOffset) / backingScale)
    }

    /// a closed window keeps its contents alive until the next event otherwise.
    func clearContents() {

        contentScale = scale

        }
    }

    /// The hit pad and outline shown while the sticker is being edited.
    func setEditingChrome(_ visible: Bool) {
        isShowingEditingChrome = visible
        withoutAnimation {
            hitPadLayer.isHidden = !visible
            outlineLayer.isHidden = !visible
        }
    }

    /// Layer-hosting views don't pass the backing scale to their sublayers, so the
    /// dashed outline (the only layer that draws vector content) gets it here:
    /// when the view joins a window and whenever that window's scale changes.
    override func viewDidMoveToWindow() {
        super.viewDidMoveToWindow()
        matchOutlineToBackingScale()
    }

    override func viewDidChangeBackingProperties() {
        super.viewDidChangeBackingProperties()
        matchOutlineToBackingScale()
        if let scale = window?.backingScaleFactor { onBackingScaleChange?(scale) }
    }

    private func matchOutlineToBackingScale() {
        guard let scale = window?.backingScaleFactor else { return }
        withoutAnimation { outlineLayer.contentsScale = scale }
    }

    override func setFrameSize(_ newSize: NSSize) {
        super.setFrameSize(newSize)
        layoutStickerLayers()
    }

    private func layoutStickerLayers() {
        withoutAnimation {
            hitPadLayer.frame = bounds
            outlineLayer.frame = bounds
            contentLayer.bounds = CGRect(origin: .zero, size: contentPointSize)
            contentLayer.position = CGPoint(x: bounds.midX, y: bounds.midY)
            updateOutlinePath()
        }
    }

    private func updateOutlinePath() {
        let box = Self.boundingSize(of: contentPointSize, scale: contentScale, rotation: contentRotation)
        let rect = CGRect(x: bounds.midX - box.width / 2, y: bounds.midY - box.height / 2,
                          width: box.width, height: box.height).insetBy(dx: -2, dy: -2)
        outlineLayer.path = CGPath(rect: rect, transform: nil)
    }

    private func withoutAnimation(_ body: () -> Void) {
        CATransaction.begin()
        CATransaction.setDisableActions(true)
        body()
        CATransaction.commit()
    }

    // MARK: Events

    /// The first click on a sticker of an inactive app must reach us.
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }
    override var mouseDownCanMoveWindow: Bool { false }
    override var acceptsFirstResponder: Bool { true }

    override func mouseDown(with event: NSEvent) {
        let editing = (window as? StickerPanel)?.isEditing ?? false
        guard editing else {
            // Inactive stickers absorb single clicks; a double-click starts editing.
            if event.clickCount == 2 { onDoubleClick?() }
            return
        }
        window?.performDrag(with: event)
        onDragEnded?()
    }

    override func keyDown(with event: NSEvent) {
        if onKeyDown?(event) == true { return }
        super.keyDown(with: event)
    }

    override func magnify(with event: NSEvent) {
        onMagnify?(event)
    }

    override func rotate(with event: NSEvent) {
        onRotate?(event)
    }
}
```

```swift
import AppKit
import os

/// Debug tool for reviewing the style recipes by eye (spec section 8):
/// `build/Stickermine.app/Contents/MacOS/Stickermine -styleGallery` renders
/// Maple and generated test shapes in every style into PNGs in a new folder
/// under the temporary directory, prints the folder's path and quits. It never
/// touches the library and opens no window.
///
/// Per subject it writes one transparent PNG per variant, exactly the bitmap a
/// sticker window shows (Core Animation adds the drop shadow on screen, so it
/// isn't in these), and `<subject>-sheet.png`: every variant, labelled, on a
/// light row and a dark row, with an approximate drop shadow drawn by Core
/// Graphics. `timings.txt` starts with the Puffy kernel's compile time, then
/// lists each render's pixel size, time and Puffy recipe.
enum StyleGallery {
    static let launchArgument = "-styleGallery"
    static let backingScale: CGFloat = 2
    /// Generated shapes are this many pixels on the long side (300 pt at 2×).
    static let shapeLongSide = 600

    /// Generated test shapes: a plain convex shape, a hole, sharp concave
    /// corners, a thin bar, a whole-image rectangle, a cutout with a light halo
    /// (what a 512 px Vision mask leaves) and a Display P3 colour outside sRGB.
    enum Shape: String, CaseIterable {
        case disc, ring, star, bar, window, fringe, p3
    }

    struct Subject {
        let name: String
        let image: CGImage
        let pointSize: CGSize
        var rotation: Double = 0
        var flipped: Bool = false
    }

    struct Variant {
        let name: String
        let style: StickerStyle
        let closesRim: Bool
        let usesPuffyKernel: Bool
    }

    /// UI order; each comparison variant follows its style.
    static let variants: [Variant] = [
        Variant(name: "puffy", style: .puffy, closesRim: true, usesPuffyKernel: true),
        Variant(name: "puffy-builtin", style: .puffy, closesRim: true, usesPuffyKernel: false),
        Variant(name: "outline", style: .outline, closesRim: true, usesPuffyKernel: true),
        Variant(name: "outline-open", style: .outline, closesRim: false, usesPuffyKernel: true),
        Variant(name: "shadow", style: .shadow, closesRim: true, usesPuffyKernel: true),
        Variant(name: "none", style: .none, closesRim: true, usesPuffyKernel: true),
    ]

    private static let log = Logger(subsystem: "com.ethan.stickermine", category: "gallery")

    /// Maple at her natural size, Maple turned 30° and flipped (Puffy's light
    /// must still come from the top-left), and every generated shape.
    static func defaultSubjects(maple: CGImage?) -> [Subject] {
        var subjects: [Subject] = []
        if let maple {
            let size = CGSize(width: CGFloat(maple.width) / backingScale, height: CGFloat(maple.height) / backingScale)
            subjects.append(Subject(name: "maple", image: maple, pointSize: size))
            subjects.append(Subject(name: "maple-turned", image: maple, pointSize: size, rotation: .pi / 6, flipped: true))
        }
        for shape in Shape.allCases {
            let image = image(of: shape, longSide: shapeLongSide)
            let size = CGSize(width: CGFloat(image.width) / backingScale, height: CGFloat(image.height) / backingScale)
            subjects.append(Subject(name: shape.rawValue, image: image, pointSize: size))
        }
        return subjects
    }

    /// A premultiplied RGBA image of `shape`, `longSide` px on its long side,
    /// with a 2 px transparent border like a cropped master (spec section 6.8).
    static func image(of shape: Shape, longSide: Int) -> CGImage {
        let side = max(longSide, 16)
        let size: (Int, Int)
        switch shape {
        case .bar: size = (side, max(8, side / 10))
        case .window: size = (side, side * 2 / 3)
        default: size = (side, side)
        }
        let space = CGColorSpace(name: shape == .p3 ? CGColorSpace.displayP3 : CGColorSpace.sRGB)!
        let context = CGContext(data: nil, width: size.0, height: size.1, bitsPerComponent: 8, bytesPerRow: 0,
                                space: space, bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!
        let box = CGRect(x: 0, y: 0, width: size.0, height: size.1).insetBy(dx: 2, dy: 2)
        func color(_ r: CGFloat, _ g: CGFloat, _ b: CGFloat, _ a: CGFloat = 1) -> CGColor {
            CGColor(colorSpace: space, components: [r, g, b, a])!
        }
        func gradient(in path: CGPath, from top: CGColor, to bottom: CGColor) {
            context.saveGState()
            context.addPath(path)
            context.clip(using: .evenOdd)
            let colors = [top, bottom] as CFArray
            let gradient = CGGradient(colorsSpace: space, colors: colors, locations: [0, 1])!
            context.drawLinearGradient(gradient, start: CGPoint(x: box.midX, y: box.maxY),
                                       end: CGPoint(x: box.midX, y: box.minY), options: [])
            context.restoreGState()
        }
        let orange = color(1, 0.62, 0.2)
        let purple = color(0.45, 0.2, 0.75)
        switch shape {
        case .disc:
            gradient(in: CGPath(ellipseIn: box, transform: nil), from: orange, to: purple)
        case .ring:
            let path = CGMutablePath()
            path.addEllipse(in: box)
            path.addEllipse(in: box.insetBy(dx: box.width * 0.3, dy: box.height * 0.3))
            gradient(in: path, from: orange, to: purple)
        case .star:
            let path = CGMutablePath()
            let outer = box.width / 2
            let inner = outer * 0.4
            for index in 0..<10 {
                let radius = index.isMultiple(of: 2) ? outer : inner
                let angle = CGFloat.pi / 2 + CGFloat(index) * .pi / 5
                let point = CGPoint(x: box.midX + radius * cos(angle), y: box.midY + radius * sin(angle))
                if index == 0 { path.move(to: point) } else { path.addLine(to: point) }
            }
            path.closeSubpath()
            gradient(in: path, from: color(1, 0.85, 0.2), to: color(0.95, 0.45, 0.1))
        case .bar:
            let radius = box.height / 2
            gradient(in: CGPath(roundedRect: box, cornerWidth: radius, cornerHeight: radius, transform: nil),
                     from: color(0.2, 0.7, 0.95), to: color(0.1, 0.35, 0.8))
        case .window:
            let corner = min(box.width, box.height) * 0.04
            gradient(in: CGPath(roundedRect: box, cornerWidth: corner, cornerHeight: corner, transform: nil),
                     from: color(0.93, 0.95, 0.98), to: color(0.78, 0.82, 0.9))
            context.setFillColor(color(0.2, 0.45, 0.9))
            for row in 0..<3 {
                let y = box.maxY - box.height * (0.25 + 0.2 * CGFloat(row))
                context.fill(CGRect(x: box.minX + box.width * 0.1, y: y, width: box.width * 0.8, height: box.height * 0.08))
            }
        case .fringe:
            // An opaque disc inside a 4 px ring of light pixels at alpha 0.3.
            context.setFillColor(color(1, 1, 1, 0.3))
            context.fillEllipse(in: box)
            context.setFillColor(color(0.1, 0.55, 0.5))
            context.fillEllipse(in: box.insetBy(dx: 4, dy: 4))
        case .p3:
            context.setFillColor(color(1, 0, 0))
            context.fillEllipse(in: box)
        }
        return context.makeImage()!
    }

    /// Renders every subject in every variant into `folder` (created if needed)
    /// and returns the files written, timings last.
    @discardableResult
    static func run(subjects: [Subject], into folder: URL) throws -> [URL] {
        try FileManager.default.createDirectory(at: folder, withIntermediateDirectories: true)
        var written: [URL] = []
        // Compile the kernel first, so its one-off cost isn't in a render's time.
        let kernel = PuffyKernel.compiled
        var timings = [kernel.kernel != nil
                       ? "# Puffy kernel compiled in \(Int(kernel.seconds * 1000)) ms"
                       : "# Puffy kernel failed to compile: \(String(describing: kernel.error))",
                       "subject\tvariant\tpixels\tms\tpuffy"]
        for subject in subjects {
            var cells: [(variant: Variant, image: CGImage, margin: Double, shadow: StyleParameters)] = []
            for variant in variants {
                let options = StyleRenderer.Options(contents: .image, closesRim: variant.closesRim,
                                                    usesPuffyKernel: variant.usesPuffyKernel)
                let renderer = StyleRenderer(masterProvider: { _ in subject.image }, options: options)
                let request = RenderRequest(sticker: UUID(), style: variant.style, flipped: subject.flipped,
                                            rotation: subject.rotation, pointSize: subject.pointSize,
                                            backingScale: backingScale)
                let start = Date()
                let rendered = try renderer.renderNow(request)
                let milliseconds = Date().timeIntervalSince(start) * 1000
                let contents = rendered.contents as AnyObject
                guard CFGetTypeID(contents) == CGImage.typeID else { continue }
                let image = contents as! CGImage
                let url = folder.appendingPathComponent("\(subject.name)-\(variant.name).png")
                try MasterImage.pngData(image, pixelsPerPoint: Double(backingScale)).write(to: url, options: .atomic)
                written.append(url)
                let path = variant.style == .puffy ? (renderer.lastPuffyPath?.rawValue ?? "?") : "-"
                timings.append("\(subject.name)\t\(variant.name)\t\(image.width)x\(image.height)\t"
                               + String(format: "%.1f", milliseconds) + "\t\(path)")
                let parameters = request.onScreenParameters(
                    sourceLongSide: Double(max(subject.image.width, subject.image.height)))
                cells.append((variant, image, parameters.shadowMargin(for: variant.style), parameters))
            }
            if let sheet = contactSheet(cells) {
                let url = folder.appendingPathComponent("\(subject.name)-sheet.png")
                try MasterImage.pngData(sheet, pixelsPerPoint: Double(backingScale)).write(to: url, options: .atomic)
                written.append(url)
            }
        }
        let timingsURL = folder.appendingPathComponent("timings.txt")
        try (timings.joined(separator: "\n") + "\n").write(to: timingsURL, atomically: true, encoding: .utf8)
        written.append(timingsURL)
        return written
    }

    /// Every variant side by side on a light row and a dark row, labelled, with
    /// a Core Graphics drop shadow approximating the layer shadow.
    static func contactSheet(_ cells: [(variant: Variant, image: CGImage, margin: Double, shadow: StyleParameters)]) -> CGImage? {
        guard !cells.isEmpty, let space = CGColorSpace(name: CGColorSpace.sRGB) else { return nil }
        let label = 36
        let margin = Int(cells.map(\.margin).max()?.rounded(.up) ?? 0) + 16
        let cellWidth = (cells.map(\.image.width).max() ?? 0) + 2 * margin
        let cellHeight = (cells.map(\.image.height).max() ?? 0) + 2 * margin
        let width = cellWidth * cells.count
        let height = 2 * cellHeight + label
        guard let context = CGContext(data: nil, width: width, height: height, bitsPerComponent: 8, bytesPerRow: 0,
                                      space: space, bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)
        else { return nil }
        context.setFillColor(CGColor(gray: 0.93, alpha: 1))
        context.fill(CGRect(x: 0, y: cellHeight, width: width, height: cellHeight + label))
        context.setFillColor(CGColor(gray: 0.16, alpha: 1))
        context.fill(CGRect(x: 0, y: 0, width: width, height: cellHeight))
        for (column, cell) in cells.enumerated() {
            for row in 0..<2 {
                let x = column * cellWidth + (cellWidth - cell.image.width) / 2
                let y = row * cellHeight + (cellHeight - cell.image.height) / 2
                context.saveGState()
                if cell.variant.style != .none {
                    context.setShadow(offset: CGSize(width: 0, height: -cell.shadow.shadowOffset),
                                      blur: CGFloat(cell.shadow.shadowRadius),
                                      color: CGColor(gray: 0, alpha: CGFloat(cell.shadow.shadowOpacity)))
                }
                context.draw(cell.image, in: CGRect(x: x, y: y, width: cell.image.width, height: cell.image.height))
                context.restoreGState()
            }
        }
        NSGraphicsContext.saveGraphicsState()
        NSGraphicsContext.current = NSGraphicsContext(cgContext: context, flipped: false)
        let attributes: [NSAttributedString.Key: Any] = [
            .font: NSFont.systemFont(ofSize: 20, weight: .medium),
            .foregroundColor: NSColor(white: 0.2, alpha: 1),
        ]
        for (column, cell) in cells.enumerated() {
            (cell.variant.name as NSString).draw(
                at: NSPoint(x: column * cellWidth + 12, y: 2 * cellHeight + 8), withAttributes: attributes)
        }
        NSGraphicsContext.restoreGraphicsState()
        return context.makeImage()
    }

    /// A new folder under the temporary directory, named after the time.
    static func defaultFolder(now: Date = Date()) -> URL {
        let formatter = DateFormatter()
        formatter.locale = Locale(identifier: "en_US_POSIX")
        formatter.dateFormat = "yyyyMMdd-HHmmss"
        return FileManager.default.temporaryDirectory
            .appendingPathComponent("stickermine-gallery-\(formatter.string(from: now))", isDirectory: true)
    }

    /// Runs the gallery off the main thread, prints where it went and quits.
    @MainActor
    static func runAndQuit() {
        let subjects = defaultSubjects(maple: BundledImages.cgImage(named: BundledImages.mapleName))
        let folder = defaultFolder()
        Task.detached {
            do {
                let files = try run(subjects: subjects, into: folder)
                print("Style gallery: \(files.count) files in \(folder.path)")
                log.notice("style gallery: \(files.count) files in \(folder.path, privacy: .public)")
            } catch {
                print("Style gallery failed: \(error)")
                log.error("style gallery failed: \(String(describing: error), privacy: .public)")
            }
            await MainActor.run { NSApp.terminate(nil) }
        }
    }
}
```

```swift
import AppKit
import os

/// Temporary (M2, styles added in M3): `open Stickermine.app --args
/// -debugPlaceMaple [style|all]` saves the bundled Maple into the library as
/// an ordinary sticker (PNG first, then the index) and places her centred on
/// the mouse pointer: once in Shadow style without a style argument, once in
/// the named style (`puffy`, `outline`, `shadow`, `none`), or four times side
/// by side in UI order for `all`. Together the placements fit within half of
/// that display. So restore, persistence, display changes and the styles can
/// be checked end to end before capture exists. M4 deletes this file and its
/// branch in AppDelegate once real captures can be placed.
enum DebugMaple {
    static let launchArgument = "-debugPlaceMaple"
    /// Space between side-by-side Maples, in points.
    static let gap: CGFloat = 40
    private static let log = Logger(subsystem: "com.ethan.stickermine", category: "debug")

    /// The styles asked for by the argument after `-debugPlaceMaple`; Shadow
    /// when there is none or it isn't a style.
    static func styles(in arguments: [String]) -> [StickerStyle] {
        guard let index = arguments.firstIndex(of: launchArgument), index + 1 < arguments.count else {
            return [.shadow]
        }
        let word = arguments[index + 1].lowercased()
        if word == "all" { return StickerStyle.allCases }
        return StickerStyle(rawValue: word).map { [$0] } ?? [.shadow]
    }

    @MainActor
    static func place(library: LibraryController, stickers: StickerManager, screens: ScreenProvider,
                      styles: [StickerStyle] = [.shadow]) {
        guard !library.isReadOnly else {
            log.error("library is read-only; Maple not placed")
            return
        }
        guard let maple = BundledImages.cgImage(named: BundledImages.mapleName) else {
            log.error("Maple asset missing")
            return
        }
        let id = UUID()
        let pixelsPerPoint = 2.0  // Maple.png is stored @2x
        let store = library.store
        let styles = styles.isEmpty ? [StickerStyle.shadow] : styles
        Task.detached {
            do {
                let data = try MasterImage.pngData(maple, pixelsPerPoint: pixelsPerPoint)
                try store.writePNG(data, for: id)
            } catch {
                log.error("writing Maple's PNG failed: \(error.localizedDescription, privacy: .public)")
                return
            }
            await MainActor.run {
                commit(id: id, image: maple, pixelsPerPoint: pixelsPerPoint, styles: styles,
                       library: library, stickers: stickers, screens: screens)
            }
        }
    }

    /// The centres and the common point size of `count` side-by-side copies of
    /// a `natural`-sized sticker around `pointer`, fitted within half of `frame`.
    static func layout(count: Int, natural: CGSize, pointer: CGPoint, frame: CGRect) -> (size: CGSize, centers: [CGPoint]) {
        let n = CGFloat(max(count, 1))
        let fit = min(1, (frame.width / 2 - gap * (n - 1)) / n / natural.width, frame.height / 2 / natural.height)
        let size = CGSize(width: natural.width * fit, height: natural.height * fit)
        let step = size.width + gap
        let centers = (0..<max(count, 1)).map { index in
            CGPoint(x: pointer.x + (CGFloat(index) - (n - 1) / 2) * step, y: pointer.y)
        }
        return (size, centers)
    }

    @MainActor
    private static func commit(id: UUID, image: CGImage, pixelsPerPoint: Double, styles: [StickerStyle],
                               library: LibraryController, stickers: StickerManager, screens: ScreenProvider) {
        let record = StickerRecord(id: id, created: Date(), pixelWidth: image.width, pixelHeight: image.height,
                                   pixelsPerPoint: pixelsPerPoint, lastStyle: styles[0])
        library.mutate { $0.stickers.append(record) }
        let pointer = NSEvent.mouseLocation
        guard let display = StickerManager.display(containing: pointer, in: screens.currentDisplays()) else { return }
        let plan = layout(count: styles.count, natural: record.naturalPointSize, pointer: pointer, frame: display.frame)
        for (style, center) in zip(styles, plan.centers) {
            let placement = stickers.place(sticker: id, style: style, centerOnScreen: center, pointSize: plan.size)
            log.notice("placed Maple \(id.uuidString, privacy: .public) as \(placement?.uuidString ?? "nothing", privacy: .public) (\(style.rawValue, privacy: .public))")
        }
    }
}
```
