# App shell checks (M6)

M6's app shell (spec sections 13, 12, 14 and 16) needs a person at the Mac: real launches from Finder and at login, a second copy, System Settings, the menu bar, focus between real apps, screenshots, screen sharing and recordings. An agent executing the plan asks Ethan to do each action and writes down what he reports and the named log lines; it never fills in a Result itself. Rows (or, in row 15b, apps) that need something that isn't there (a second Mac, a Mac on macOS 26.x, an AirPlay receiver or iPad, a published release) get `not run: <reason>`.

## Setup

Run these in bash or zsh, not fish.

1. Keep the real library and settings out of the way (the checks start from a first run and change every setting). Run this block once; to reinstall after a fix, run only `./install.sh`:

   ```bash
   LIB="$HOME/Library/Application Support/com.ethan.stickermine"
   pkill -x Stickermine || true
   if [ -e "$LIB" ] && [ ! -e "$LIB.before-m6" ]; then mv "$LIB" "$LIB.before-m6"; fi
   [ -e "$HOME/stickermine-defaults-before-m6.plist" ] || defaults export com.ethan.stickermine "$HOME/stickermine-defaults-before-m6.plist" 2>/dev/null || true
   defaults delete com.ethan.stickermine 2>/dev/null || true
   ```

2. `./install.sh`. It must print `Signing with: DEA1A3749B06CF3619F72152EFC35A48E380C4E4` and `Running instances: 1`. It launches `/Applications/Stickermine.app` with `open` (a user launch, so this is the first run).
3. In a second terminal: `log stream --style compact --predicate 'subsystem == "com.ethan.stickermine"'`.
4. In the first terminal, define two helpers (the library is saved 0.5 s after a change: wait a second before using them):

   ```bash
   LIB="$HOME/Library/Application Support/com.ethan.stickermine"
   counts() { python3 -c 'import json,sys; d=json.load(open(sys.argv[1])); print("stickers", len(d["stickers"]), "tutorial", sum(1 for s in d["stickers"] if s.get("tutorial")), "placements", sum(len(r["placements"]) for r in d["displays"].values()))' "$LIB/library.json"; }
   setting() { defaults read com.ethan.stickermine "$1" 2>/dev/null || echo "(default)"; }
   ```
